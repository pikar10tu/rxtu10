# แผนตรวจข้อสอบยกเครื่องทั้งคลัง (ก.ย. 2026)

## ข้อตัดสินใจ (user 27 ก.ย. 2026)
- คนตัดสิน 🔴 + หมวดเสี่ยง = **ทีมวิชาการ**
- ข้อกำกวม = **เสนอโจทย์ฉบับแก้ก่อน** แก้ไม่ได้ค่อยปลด
- **ตรวจให้ครบคลังก่อนเปิดเว็บ** (ไม่ทยอยปล่อย)
- รางวัลตรวจข้อปกติ `REVIEW_REWARD` 5000 → **1000** · โบนัสข้อที่ถูกข้าม +5000/คนเหมือนเดิม · ข้อที่กดข้ามแล้ว**ไม่ขึ้นอีก**ในคิวของคนนั้น (ถาวรผ่าน `reviewSkips`)
- อยากให้เพื่อนเห็น **ระดับความมั่นใจของ AI ตอนเฉลย** → ทำหลังนำร่อง (ต้องวัดก่อนว่าความมั่นใจเชื่อได้)

## บทเรียนรอบก่อน
- AI ตรวจโดย**เห็นเฉลย** → คล้อยตาม เฉลยผิดหลุด
- ข้อ K + น้ำผลไม้: เฉลยไม่ผิดแต่**กำกวม** (หลายตัวเลือกเถียงได้)
- ข้อ Antacid + Statin: AI ให้**เหตุผลผิด** (บอกกินกลางคืน จริงๆ คือการดูดซึม)

## ขั้นตอน
0. **เตรียม** — backup ทั้งคลังเป็นไฟล์ · คงจอปิดปรับปรุง (ล็อกการแก้) · พักรีพอร์ท AI เก่า 260 ใบ
1. **ชุดวัดฝีมือ ~50 ข้อ** — ข้อที่ user ปลดไปแล้ว (รู้ว่าเสีย) ปนข้อดี ตรวจแบบไม่รู้เฉลย · ผ่านเมื่อจับข้อเสียได้ ≥90% และแจ้งข้อดีว่ามีปัญหาไม่เยอะเกินไป
2. **ตรวจ 3 ด่านทุกข้อ** — (1) Opus + Sonnet ทำแยกกันโดยไม่เห็นเฉลย (2) เทียบเฉลย + หาตัวเลือกที่เถียงได้ (3) ตรวจเหตุผล/กลไกในคำอธิบาย
   - 🟢 ผ่าน · 🟡 เฉลยถูกแต่คำอธิบาย/ถ้อยคำต้องแก้ · 🔴 เฉลยน่าจะผิด/กำกวม
   - บันทึกความมั่นใจ 0–100 ต่อข้อ
   - หมวดกฎหมาย/เภสัชกรรมปฏิบัติ/บัญชียาหลัก/แนวทางไทย → ส่งคนดูทุกข้อ แม้ 🟢
3. **ทีมวิชาการตัดสิน** — หน้าเดียวเห็นโจทย์/เฉลยเดิม/คำตอบ AI 2 ตัว/เหตุผล/ฉบับแก้ · ปุ่ม แก้ตามนี้/คงไว้/ปลด/แก้เอง · เรียง 🔴 → 🟡 → หมวดเสี่ยง · สุ่ม 🟢 5% ถ้าเจอผิด >2–3% ย้อนปรับวิธี
4. **เขียนลงเว็บ** — เฉพาะที่คนยืนยัน เป็นรอบ backup ก่อนทุกรอบ เก็บประวัติใครตัดสิน/แก้อะไร
5. **เปิดเว็บ** เมื่อครบคลัง
