# เช็คลิสต์เทสมือ — หน้าตรวจข้อสอบ (Report Case Flow)

ใช้เทสหน้า `/review` เวอร์ชันใหม่บนเว็บจริง (ไม่ใช่ dev) หลัง deploy แล้ว
ทำตามลำดับ ข้อไหนผลไม่ตรงตามที่เขียนไว้ให้หยุดแล้วแจ้งทีมพัฒนา

## ของที่ต้องเตรียมก่อนเริ่ม

- **บัญชีนักศึกษา (role: student)** 1 บัญชี — ใช้สร้างรีพอร์ททดสอบ
- **บัญชีทีมวิชาการ/แอดมิน (role: academic หรือ admin)** อย่างน้อย **2 บัญชี** — บัญชี A ใช้ทดสอบส่วนใหญ่, บัญชี B ใช้เฉพาะข้อ 12 (สองเครื่องปิดพร้อมกัน) และข้อ 13 (คนแก้ไม่ขึ้นให้ตัวเอง)
- **บัญชีอาจารย์ (role: instructor)** 1 บัญชี — ใช้เฉพาะข้อ 14
- มีข้อสอบอย่างน้อย 1 ข้อที่ **ไม่มีกลุ่มโรค** (pleGroup ว่าง) ค้างอยู่ในคิว — ถ้าไม่แน่ใจว่ามีไหม ให้เข้า `/review` ด้วยบัญชีแอดมิน กด "ดูรายการ" ในกล่อง "ข้อที่รอดำเนินการ" แล้วดูกอง "ไม่มีกลุ่มโรค"

---

## ส่วนที่ 1 — สร้างรีพอร์ททดสอบ (ต้องทำก่อน ข้อ 8-13 ถึงจะมีรีพอร์ทให้ตัดสิน)

**1. สร้างรีพอร์ท**
เข้าสู่ระบบด้วย **บัญชีนักศึกษา** → เมนู **Quiz** → ทำข้อสอบจนเจอข้อไหนก็ได้ → ใต้ตัวเลือกจะมีปุ่ม **"🚩 แจ้งข้อผิด"** → กด → เลือกเหตุผล 1 ป้าย (เช่น "เฉลยผิด") → (จะพิมพ์รายละเอียดเพิ่มหรือไม่ก็ได้) → กด **"ส่ง"**
**ผลที่ควรเห็น:** ปุ่มเปลี่ยนเป็น "🚩 แจ้งแล้ว ✓" (กดซ้ำไม่ได้อีกในข้อเดียวกัน) — **จดชื่อ/โจทย์ข้อที่แจ้งไว้** จะใช้อ้างอิงข้อ 8

---

## ส่วนที่ 2 — การ์ดตรวจข้อปกติ (ล็อกอินด้วยบัญชีแอดมิน/วิชาการ A → เข้า `/review`)

**2. ถูกต้อง (2 แตะ)**
เปิดข้อไหนก็ได้ในคิวปกติ (ไม่ใช่การ์ดรีพอร์ท 🚩) → อ่านโจทย์ → กด **"✅ ถูกต้อง ส่งผล"** → กด "ยืนยัน" ในกล่องถาม
**ผลที่ควรเห็น:** ขึ้น toast "ส่งผลตรวจแล้ว ขอบคุณ!" ข้อถัดไปเด้งขึ้นเอง → เลื่อนลงล่างสุดของหน้า ดูกล่อง **"🏅 ใครตรวจไปกี่ข้อ"** ตัวเลขข้างชื่อบัญชี A ต้องบวกเพิ่ม 1

**3. แก้เฉลย (แก้ชั้นตัดสิน)**
เจอข้อที่ต้องแก้จริง → กด **"มีจุดผิด"** → กด **"✏️ แก้ข้อนี้"** → แก้โจทย์/ตัวเลือก/เฉลยจริง (ไม่ใช่แค่คำอธิบาย) → พิมพ์เหตุผลในช่อง "แก้อะไร/ทำไม (บังคับ)" → กด **"บันทึก = ผ่านตรวจ"** → ยืนยัน
**ผลที่ควรเห็น:** ก่อนพิมพ์เหตุผลปุ่มบันทึกเป็นสีเทากดไม่ได้ พอกรอกครบถึงกดได้ → toast "แก้และตรวจผ่านแล้ว ขอบคุณ!" → นับเป็นข้อที่ตรวจแล้วทันที (ตัวเลขในกระดาน 🏅 +1) → ข้อนี้ต้องไม่วนกลับมาให้ตัวเองตรวจซ้ำ

**4. แก้แค่คำอธิบาย (ไม่แตะเฉลย)**
เปิดข้อไหนก็ได้ → กด **"＋ เพิ่ม เหตุผล / เรฟ / หมายเหตุถึงนักศึกษา"** ให้กางออก → กด **"📝 แก้คำอธิบายเฉลย"** → พิมพ์/แก้เฉพาะช่องคำอธิบายเฉลย (ไม่แตะโจทย์/ตัวเลือก/เฉลย)
**ผลที่ควรเห็น:** ปุ่ม "บันทึกการแก้" เป็นสีเทากดไม่ได้ตอนยังไม่พิมพ์อะไร พอพิมพ์แล้วปุ่มเปลี่ยนเป็นสีน้ำเงินกดได้ และข้อความใต้ปุ่มบอกว่า **"✅ บันทึกแล้วตรวจต่อได้เลย ผลตรวจเดิมยังอยู่"** (ต่างจากข้อ 3 ที่ข้อความจะบอกว่านับว่าตรวจผ่านทันที) → กดบันทึก → toast "บันทึกแล้ว — ตรวจต่อได้เลย" → ข้อนี้ยัง**ไม่**นับว่าตรวจผ่าน ต้องกด "✅ ถูกต้อง ส่งผล" ต่ออีกที

**5. นำออก**
เจอข้อที่ผิดจนแก้ไม่คุ้ม → กด **"มีจุดผิด"** → กด **"🗑️ นำออก"** → พิมพ์เหตุผล (บังคับ) → กด **"นำออก"** → ยืนยัน
**ผลที่ควรเห็น:** toast "นำข้อนี้ออกแล้ว" → กลับไปดูกระดาน 🏅 ตัวเลขของบัญชี A ต้องบวกเพิ่ม 1 (แม้ "นำออก" ไม่ใช่ "ถูกต้อง" ก็ยังนับเครดิตให้)

**6. ไม่มีกลุ่มโรค**
เปิดข้อที่ยังไม่มีกลุ่มโรค (ดูวิธีหาในหัวข้อ "ของที่ต้องเตรียม")
**ผลที่ควรเห็น:** เหนือปุ่มตัดสินมีกรอบสีเหลืองเขียนว่า "ต้องเลือกกลุ่มโรคก่อนส่ง…" และมีตัวเลือกกลุ่มโรคให้กรอกโผล่มาเอง (ไม่ต้องกดอะไรเพิ่ม) ปุ่ม "✅ ถูกต้อง ส่งผล" เป็นสีเทากดไม่ได้ พร้อมข้อความเตือนใต้ปุ่ม "เลือกกลุ่มโรคก่อนถึงจะส่งผลได้" → เลือกกลุ่มโรคแล้วปุ่มต้องกดได้ทันที

**7. ข้าม**
เปิดข้อไหนก็ได้ → กด **"ข้ามข้อนี้"**
**ผลที่ควรเห็น:** ข้อนี้หายไปจากตา เด้งไปข้อถัดไป ไม่มีอะไรถูกบันทึกลง Firestore (ตรวจได้คร่าวๆ จากตัวเลขกระดาน 🏅 ไม่ขยับ) ถ้าข้ามจนหมดคิว จะเห็นข้อความ "ข้ามไว้ N ข้อ — ยังไม่ได้ตรวจ" พร้อมปุ่ม "ดูข้อที่ข้ามอีกรอบ"

## ส่วนที่ 3 — การ์ดรีพอร์ท 🚩 (ต้องเป็นบัญชี academic/admin เท่านั้น ไม่ใช่ instructor)

ก่อนเริ่มส่วนนี้ให้แน่ใจว่ามีรีพอร์ทค้างจากข้อ 1 แล้ว — เปิดหน้า `/review` ด้วยบัญชี A จะเห็นแถบสีส้ม **"🚩 มีข้อที่ถูกแจ้ง N ข้อ"** ด้านบน และการ์ดรีพอร์ทขึ้นก่อนการ์ดตรวจปกติเสมอ

**8. ไม่ผิด (ผู้แจ้งได้จดหมาย ไม่มีรางวัล)**
เปิดการ์ดรีพอร์ทของข้อที่เพิ่งแจ้งในข้อ 1 → อ่านคำถาม **"ผู้แจ้งพูดถูกไหม?"** → กด **"ไม่ผิด ข้อสอบถูกแล้ว"** → (จะพิมพ์คำอธิบายให้ผู้แจ้งหรือไม่ก็ได้ ไม่บังคับ) → กด **"ปิดรีพอร์ท"** → ยืนยัน
**ผลที่ควรเห็น:** toast "จัดการแล้ว ขอบคุณ!" **ไม่มี** ข้อความเรื่องรางวัลต่อท้าย → กระดาน 🏅 ของบัญชี A +1 → สลับไปล็อกอินด้วย**บัญชีนักศึกษาที่แจ้ง** → เปิด Home → กด 📬 "กล่องจดหมาย" มุมขวาบน → ต้องเห็นจดหมายหัวข้อ **"ผลการแจ้งข้อสอบ"** (ไม่มีเหรียญให้เก็บ)

**9. แก้ (รางวัล + เครดิต)**
สร้างรีพอร์ทใหม่อีก 1 ข้อจากบัญชีนักศึกษา (ทำซ้ำข้อ 1 กับข้อสอบข้ออื่น) → กลับมาบัญชี A → เปิดการ์ดรีพอร์ทของข้อนี้ → กด **"ผิดจริง"** → กด **"✏️ แก้ข้อนี้"** → แก้เนื้อหาจริง + พิมพ์เหตุผล → กด **"บันทึก + ปิดรีพอร์ท"** → ยืนยัน
**ผลที่ควรเห็น:** toast แจ้งว่าจัดการเสร็จ + ส่งรางวัลให้ผู้แจ้ง → กระดาน 🏅 ของบัญชี A +1 → สลับไปบัญชีนักศึกษา → กล่องจดหมาย ต้องเห็นจดหมายหัวข้อ **"รางวัลแจ้งข้อสอบผิด"** มีเหรียญให้กดรับ (กดรับแล้วเหรียญต้องเข้าจริง)

**10. นำออก**
สร้างรีพอร์ทใหม่อีก 1 ข้อ → เปิดการ์ดรีพอร์ท → กด "ผิดจริง" → กด **"🗑️ นำออก"** → พิมพ์เหตุผล → กด **"นำออก + ปิดรีพอร์ท"** → ยืนยัน
**ผลที่ควรเห็น:** เหมือนข้อ 9 (รางวัลเข้าจดหมายผู้แจ้ง + เครดิตกระดาน 🏅 บัญชี A +1) ต่างกันที่ข้อสอบถูกถอนเผยแพร่แทนที่จะถูกแก้

**11. ข้าม**
เปิดการ์ดรีพอร์ทข้อไหนก็ได้ (ที่ยังไม่ปิด) → กด **"ข้ามข้อนี้"**
**ผลที่ควรเห็น:** การ์ดรีพอร์ทข้อถัดไปขึ้นแทน (หรือกลับไปคิวปกติถ้าไม่มีรีพอร์ทเหลือ) ไม่มีอะไรถูกเขียนลง Firestore — รีโหลดหน้าใหม่ (F5) รีพอร์ทที่ข้ามไปต้องกลับมาขึ้นให้ตรวจอีกครั้ง (การข้ามอยู่แค่ในเซสชัน)

**12. ข้อถูกลบ/นำออกไปแล้วแต่ยังมีรีพอร์ทค้าง**
สร้างรีพอร์ทใหม่ 1 ข้อ → **ก่อน**เปิดการ์ดรีพอร์ทของข้อนั้น ให้ไปที่คลังข้อสอบ (`/questions`) แล้วนำข้อนั้นออกหรือลบทิ้งด้วยวิธีอื่น (หรือให้อีกบัญชีนำออกผ่านการ์ดตรวจปกติก่อน) → กลับมา `/review` เปิดการ์ดรีพอร์ทของข้อนี้
**ผลที่ควรเห็น:** การ์ดขึ้นข้อความ "ข้อนี้ถูกนำออกหรือลบไปแล้ว" เหลือปุ่มเดียวคือ **"ปิดรีพอร์ท + ให้รางวัล"** → กด → ยืนยัน → รางวัลต้องเข้าจดหมายผู้แจ้งเหมือนเดิม

## ส่วนที่ 4 — เคสสองบัญชี (ต้องใช้บัญชีวิชาการ/แอดมิน B ด้วย)

**13. สองเครื่องปิดพร้อมกัน (ต้องได้จดหมายรางวัลฉบับเดียว ไม่ใช่สองฉบับ)**
สร้างรีพอร์ทใหม่ 1 ข้อ → เปิด `/review` พร้อมกัน 2 เครื่อง/2 แท็บ ด้วยบัญชี A และบัญชี B (หรือคนละมือถือ) ให้ทั้งคู่เห็นการ์ดรีพอร์ทข้อเดียวกัน → ทั้งสองฝั่งกด **"ไม่ผิด ข้อสอบถูกแล้ว" → "ปิดรีพอร์ท"** ให้ไล่เลี่ยกันที่สุดเท่าที่ทำได้
**ผลที่ควรเห็น:** ฝั่งที่กดช้ากว่าจะขึ้น toast **"มีคนปิดรีพอร์ทข้อนี้ไปแล้ว"** แทนข้อความสำเร็จ → เปิดกล่องจดหมายของบัญชีนักศึกษาผู้แจ้ง ต้องเจอจดหมายผลการแจ้ง **ฉบับเดียว** ไม่ใช่สองฉบับซ้อนกัน

**14. คนที่แก้ข้อไม่ขึ้นให้ตัวเองตัดสินซ้ำ**
ให้บัญชี A แก้ข้อสอบข้อหนึ่งจนผ่านตรวจ (ทำตามข้อ 3) → จากนั้นให้นักศึกษาไปแจ้งรีพอร์ทข้อ**เดียวกันนั้น**อีกครั้ง (ทำซ้ำข้อ 1 แต่เลือกข้อที่เพิ่งแก้) → ล็อกอินกลับมาด้วย**บัญชี A คนเดิม** ที่เพิ่งแก้ข้อนี้ → เปิด `/review`
**ผลที่ควรเห็น:** การ์ดรีพอร์ทของข้อนี้ต้อง**ไม่**ขึ้นให้บัญชี A เห็น (ระบบข้ามให้อัตโนมัติเพราะเป็นคนแก้ข้อนี้ล่าสุด) → ให้บัญชี B ล็อกอินเช็คแทน ต้องเห็นการ์ดรีพอร์ทของข้อนี้ตามปกติ

## ส่วนที่ 5 — สิทธิ์อาจารย์

**15. อาจารย์ไม่เห็นแบนเนอร์/การ์ดรีพอร์ท**
ล็อกอินด้วย**บัญชีอาจารย์ (role instructor)** ที่ยังมีรีพอร์ทค้างอยู่ในระบบ (ถ้าปิดหมดแล้วให้สร้างรีพอร์ทใหม่ 1 ข้อก่อน) → เข้า `/review`
**ผลที่ควรเห็น:** หน้าเข้าได้ปกติ (อาจารย์ตรวจข้อสอบได้) แต่ **ต้องไม่เห็น**แถบสีส้ม "🚩 มีข้อที่ถูกแจ้ง" และ**ต้องไม่เห็น**การ์ดรีพอร์ทเลย — เห็นแค่การ์ดตรวจข้อปกติตรงคิวของตัวเอง

---

## ส่วนที่ 6 — แอดมินซิงก์ระบบตรวจ

**16. กดซิงก์แล้วเครดิตนำออกไม่หาย**
ก่อนกด: จดตัวเลขในกระดาน 🏅 "ใครตรวจไปกี่ข้อ" ของบัญชี A ไว้ก่อน (ควรมีเครดิตจากข้อ "นำออก" ที่ทำไปแล้วในข้อ 5/10 รวมอยู่ด้วย) → ล็อกอินด้วยบัญชีแอดมิน (role admin) → ไปหน้า **Admin** → กดปุ่ม **"🔄 ซิงก์ระบบตรวจ"** → รอจนขึ้น "ซิงก์เสร็จแล้ว" (ปุ่มจะเปลี่ยนข้อความระหว่างทำงานเป็น "กำลังซิงก์…")
**ผลที่ควรเห็น:** กลับไปหน้า `/review` ตัวเลขในกระดาน 🏅 ของบัญชี A **ต้องเท่าเดิมหรือมากกว่า** ไม่ลดลง (โดยเฉพาะเครดิตจากการ "นำออก" ต้องไม่หายไป)

---

หมายเหตุท้ายเช็คลิสต์: เคส "ข้าม" ทั้งฝั่งข้อปกติ (ข้อ 7) และฝั่งรีพอร์ท (ข้อ 11) ตั้งใจให้ไม่เขียนอะไรลง Firestore เลย — ถ้าเห็นตัวเลขกระดาน 🏅 ขยับตอนกดข้าม ให้ถือว่าเป็นบั๊ก
