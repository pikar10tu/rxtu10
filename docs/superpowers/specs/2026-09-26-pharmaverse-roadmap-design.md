# Pharmaverse — โลก · เพ็ท L ใหม่ 3 เดือน · ตู้ธีม (roadmap design)

วันที่ 26 ก.ย. 2026 · สถานะ: user อนุมัติทั้ง 3 ส่วนใน brainstorm แล้ว · เอกสารนี้เป็น **ภาพรวม** —
แต่ละงานย่อย (§6) ต้องมีสเปก/แผนละเอียดของตัวเองก่อนลงมือ

## 1. ทำไม

- คนเล่นแต่ L — user จะเพิ่ม L เดือนละ 3–4 ตัว (ต.ค.–ธ.ค. 2569 รวม 10 ตัว · L 12 → 22)
- ให้ common มีที่ยืนผ่านเพ็ท L ที่ดัน common (☀️ Sol) — เมต้าหลากหลายขึ้น
- lore/flavor เดิมปนกันสองโทน (L แฟนตาซีจริงจัง · ตัวเล็กมุกเภสัช) ไม่มีโลกร่วม → ทำโลกเดียวครอบทุกตัว

## 2. โลก: Pharmaverse (ประตูอัญเชิญ)

- **แกน:** "โรคร้าย" รั่วซึมกัดกินทุกมิติ · **ผู้อัญเชิญ** = นักศึกษาเภสัช (ผู้เล่น) ใช้ความรู้เรื่องยา/การเยียวยาเป็นกุญแจเปิดประตูข้ามมิติ · แต่ละมิติส่งผู้พิทักษ์มาช่วยด้วยเหตุผลของตัวเอง
- **ต่อธีมใหม่ = "ประตูบานใหม่เปิด"** ไม่ต้องแก้โลกเดิม
- **โทนสองชั้น:** ประวัติจริงจัง · คำพูดเป็นเสียงตัวละคร (L ตามนิสัยในตำนาน · common/rare มุกเด็กเภสัชได้เต็มที่)

มิติของตัวเดิม 33 ตัว (ร่าง — ปรับได้ตอนเขียนจริงในงาน #2):

| มิติ | สมาชิก |
|---|---|
| 🏡 โลกของผู้อัญเชิญ (สัตว์ธรรมดา ใจสู้) | common + rare ทั้งหมด 🦔🐹🐭🐱🦋🐢🐺🦈🦊🐰🦉🦭 |
| 🐉 แดนตำนาน | 🐉🐲🐦‍🔥🦅🦄🐕🐍👹🐘🧞🧚 |
| 🌿 ป่าลึก | 🦁🦍🐗🦡🐼🦇 |
| 🦴 ยุคดึกดำบรรพ์ | 🦖🦣 |
| 🌊 ทะเล | 🐳 (เจ้าของร้านชำริมทะเล · 🦭 ลูกค้าประจำ) |
| 🦠 ฝั่งโรคร้าย | 👾 ไวรัส — เชื้อที่แปรพักตร์มาฝั่งเรา |
| มิติรายเดือน | ☀️🌍🌙 ฟากฟ้า · 👽🛸🤖 นอกพิกัด · ⛄🦌🐧🐻‍❄️ ดินแดนหิมะ |

**รูปแบบต่อตัว (43 ตัว):** `lore` ประวัติ 2–3 ประโยค (มาจากมิติไหน · ทำไมตอบรับการอัญเชิญ) + `quote` คำพูด 1 ประโยค (แทน `flavor` เดิม)

**อีสเตอร์เอ้ก (ห้ามเอ่ยชื่อเรื่องต้นฉบับ):** ☀️–🌍 · 🌙–👽 · 🐳–🦭 อิงคู่จากซีรีส์ GL ที่ user ชอบ
ระดับที่ใช้ได้ = "ความเอียง 23.5 องศาที่ทำให้เกิดฤดูกาล คือแรงเดียวกับที่เหวี่ยงเธอไปหาดวงอาทิตย์"
— คนรู้ก็รู้เอง ไม่โชว์ตรงๆ · ชื่อ "ซัน/องศา" โผล่เฉพาะตอนแปลงร่างบนสนาม (§3.2)

## 3. เพ็ท L ใหม่ 10 ตัว

**หลักตัวเลข:** เลขกลม (50% / 30% / 25% / 20% / 10%) ยอม off-balance นิดหน่อย เพราะเมต้าวัดที่การจัดทีม
sim (`scripts/passive-power-sim.mjs`) ใช้กันหลุดโลก ไม่ใช่จูนละเอียด
**หลักกลไก:** ตัวละ 1 กลไกใหม่ · ทุกกลไกต้องมีภาพ/เลขบนจอรีเพลย์ (ตรวจด้วยห้องแล็บตัวจด DOM แบบ 26 ก.ย.)
**เลิกกฎเหล็ก "passive ห้ามเพิ่มจังหวะหมัด"** (user สั่ง 26 ก.ย.) — คุมแค่ความยาวไฟต์รวมด้วยเทสงบเวลาที่มีอยู่

### 3.1 ต.ค. — ฟากฟ้า

| ตัว | สาย | สกิล |
|---|---|---|
| ☀️ Sol | ✊ | ออร่า: **common ทุกตัวในทีม** พลังโจมตี + เลือดสูงสุด **+50%** (ไม่มีผลกับ rare/epic/L) · นิสัยลูกพี่แบบออลไมท์ มั่นใจ พึ่งพาได้ ดันตัวไม่เก่งขึ้นมา (+ ความสดใส/ใจร้อนแบบ "ซัน") |
| 🌍 Earth | ✋ | **ฤดูตามช่องเริ่มต้นในทีม** ทำงาน 1 ครั้งทุกครั้งที่ **จบรอบ** (§3.4): ช่อง 1 ☀️ ร้อน = วงถัดไปทั้งทีมแรงขึ้น · ช่อง 2 🌧️ ฝน = ทั้งทีมฟื้น 25% ของเลือดที่หายไป · ช่อง 3 ❄️ หนาว = ศัตรูแต่ละตัว 30% ถูกแช่แข็งข้าม 1 ตา · หน้าจัดทีมต้องบอกฤดูของช่องทันทีตอนวาง |
| 🌙 Luna | ✌️ | วนตามหมัดของตัวเอง: 🌑 จันทร์ดับ 75% → 🌙 เสี้ยว 125% → 🌕 เต็มดวง 175% + แบนเนอร์ใหญ่ |

### 3.2 ร่าง "องศา"

- **เงื่อนไข:** ทีมมี ☀️ Sol **และ** ไม่มี common เลย (ไม่มี Sol = ไม่แปลงร่าง ไม่เสียสกิล)
- **ผล:** 🌍 นับเป็น common ⇒ ได้ +50% จาก Sol · **เสียสกิลฤดูกาลทั้งหมด** เหลือสเตตัสล้วน
- **บนจอ:** 🌍 ชื่อ "องศา" · ☀️ ชื่อ "ซัน" (ฝั่งจอล้วน แพทเทิร์นเดียวกับ `DUO_TITLES` — log/เอนจินแบกชื่อจริง)
- **เหตุผลบาลานซ์:** Sol+องศา+L = 35/175 แต่พาสสีฟ L ตัวเดียว · Sol+common×2 = 30/150 + พาสสีฟ common 2 ตัว ⇒ แลกกันจริง

|---|---|---|---|

คำว่า "รอบ" ในตารางนี้ = รอบตามนิยามใหม่ §3.4 (ทุกตัวตีครบ) · "ข้ามหมัด" = ข้าม 1 ตา

### 3.4 กลไกร่วมที่ต้องสร้าง

- **ศัพท์ใหม่ทั้งเกม (user เคาะ 26 ก.ย.):** **"ตา"** = 1 หมัดของเพ็ท 1 ตัว · **"รอบ"** = ทุกตัวได้ตาครบคนละ 1 ครั้ง
  ⚠️ **เปลี่ยนนิยาม `round` ในเอนจิน** — ปัจจุบัน `round` = ฝั่งละ 1 หมัด (3v3 ต้อง 3 round กว่าทุกตัวจะตีครบ)
  ⇒ ตัวนับ "รอบ N" บนจอขึ้นเร็วกว่าความรู้สึก และสกิล "ทุกต้นรอบ" ทำงานถี่กว่าที่ข้อความบอก
  นิยามใหม่: รอบจบเมื่อ **ทุกตัวที่ยังมีชีวิตทั้งสองฝั่ง** ได้ตาครบคนละ 1 ครั้งนับจากรอบก่อน
  ต้องรองรับ: ตัวตายกลางรอบ (ไม่ต้องรอ) · ตัวที่ถูกแช่แข็ง/สตั๊น (ตาที่ข้ามนับเป็นตาแล้ว) · ตีต่อของโอนิ (ไม่นับเป็นตาใหม่)
  **ผลกระทบของเดิม (ต้องทำในงาน #1 พร้อมกัน):**
  - `onRound` 7 ตัว (🐍 🐘 🦍 🐼 🦋 + คู่ 🦭🐳 regen) ทำงานน้อยลง ~3 เท่าใน 3v3 ⇒ คูณเลขชดเชยเป็นเลขกลม (เช่น 4% → 12%) แล้วเช็คด้วย sim
  - 👹 โอนิ ข้อความ "ครั้งต่อรอบ" จริงๆ นับต่อตา (ตัวนับ chain รีเซ็ตทุกตา) ⇒ แก้ข้อความเป็น "ต่อตา"
  - ตัวนับ "รอบ N" ใน BattleReplay · event `{t:'round'}` · `battleBeats`/เทสงบเวลาไฟต์ที่อ่าน round · `maxTurns` ยังนับเป็นตาเหมือนเดิม
  ใช้โดย: 🌍 ฤดูกาล · 🛸 · 🦌 · 🐻‍❄️ · ทุกสกิลต้นรอบเดิม
- **ข้ามตา (skip turn)** — ตัวเดียวใช้ร่วม ❄️ แช่แข็ง · 🛸 สตั๊น · 🐻‍❄️ จำศีล
- **บัฟตามระดับ (rarity-gated aura)** — ☀️ · อ่านระดับ "ที่นับ" (องศา = common)
- **ป้ายชื่อบนสนามตามทีม** — ขยาย `DUO_TITLES` ให้เปลี่ยน *ชื่อตัวละคร* ได้ (ซัน/องศา) ไม่ใช่แค่ชื่อสกิล
- **แบนเนอร์สกิลคู่** — หน้าเพ็ท 2 ตัวชิดกันในแบนเนอร์ · ใช้กับ ☀️🌍 · 🌙👽 · 🐳🦭 (ของเดิมด้วย)

## 4. ตู้กาชา

- **ตู้คงที่:** เลือกเป้า L ได้ทุกตัว **ยกเว้นตัวใหม่ของเดือนนั้น**
- **ตู้ธีมรายเดือน (เปิดทั้งเดือน):** อัตรา L รวมเท่าเดิม (`GACHA_RATES.legendary` + pity เดิม) · ตัวใหม่น้ำหนัก ×3 เทียบ L ตัวอื่น (ตู้ยังออกตัวอื่นได้) · การันตี/50-50 = ตัวใหม่ที่เลือกไว้หน้าตู้
- แทนโครงตู้อีเวนต์เดิม (`gachaEvent.js`: ตัวเด่น 3 ตัว + ตัวที่ยังไม่มีก่อน) · หมดเดือนตัวใหม่ย้ายเข้าตู้คงที่
- ⚠️ `gachaPity` ของตู้อีเวนต์เดิมและการันตี 50/50 มีกฎห้ามแตะอยู่ (memory passive v2) — สเปกงาน #1 ต้องตัดสินว่าตู้ธีมใช้ pity ร่วมหรือแยก
