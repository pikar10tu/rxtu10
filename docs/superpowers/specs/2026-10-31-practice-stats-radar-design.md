## 1. ฝึกตามกลุ่มโรค (pleGroup)
- หน้าควิซ: เลือกหมวดใหญ่แล้ว → แถวชิปกลุ่มโรค (`groupsOfDomain`) โผล่ใต้ · เลือกได้ 1 กลุ่ม หรือ "ทั้งหมวด"
- เลือกชุดข้อสอบ ⇒ ล้างกลุ่ม (สลับกันเหมือนหมวด/ชุดเดิม)
- `useQuestionFeed.fetchQuestions` รับ `group` → `where('pleGroup','==',group)` (แทน domain เมื่อมี)
- index ใหม่: isPublished+pleGroup+rand · isPublished+reviewStatus+pleGroup+rand — deploy index ก่อน push
- `buildMeta` นับ `groups` / `approvedGroups` ต่อ pleGroup · แอดมินกด 🔄 meta หลัง deploy
- deep link `/quiz?group=cvs` → เลือกหมวด+กลุ่มให้ (ใช้จากปุ่ม "ฝึกเลย")

## 2. เก็บสถิติรายกลุ่ม

- นับทุกโหมด: ควิซปกติ · Zen · ทบทวนข้อผิด · Time Attack

- เริ่มนับจากศูนย์ (ประวัติเก่าไม่มีกลุ่ม) — ไม่ backfill

## 3. แท็บ 📊 ผลฝึก ในหน้า Me (แท็บแรก)
- radar 21 ด้าน = PLE_GROUPS โดยรวม `other` + `sci_social` เป็นด้านเดียว · ป้ายตัวย่ออังกฤษ · SVG วาดเอง ไม่เพิ่มไลบรารี
- ด้านไม่มีข้อมูล = 0 (user เคาะ B)
- สลับมุมมอง: radar ⇄ แถบแนวนอนเรียงอ่อน→เก่ง (ด้านที่ไม่มีข้อมูลอยู่ท้าย ป้าย "ยังไม่ได้ฝึก")
- แตะด้าน/แถบ → ชื่อเต็ม ไทย+อังกฤษ · ถูก/ทำ · ปุ่ม ▶ ฝึกเลย
- "หมวดที่ควรฝึก" 3 อันดับ: % ต่ำสุดในด้านที่ทำ ≥5 ข้อ (ถ้าไม่พอ ใช้ด้านที่ยังไม่ได้ฝึก)
- "ข้อที่ผิดบ่อย" 5 ข้อ จาก `study.qcards` เรียง lapses มาก→น้อย · โหลดโจทย์ตอนเปิดแท็บเท่านั้น (≤5 reads) · แตะเพื่อดูโจทย์+เฉลย
- อ่านจาก user doc ที่มีอยู่แล้ว = 0 reads สำหรับ radar
- ไม่ทำคืนนี้: เส้นค่าเฉลี่ยรุ่น
