## 1. ลำดับเหตุการณ์ในไฟต์ (ของเดิม + จุดที่ของใหม่เสียบ)

ของเดิมอ่านจาก `battleEngine.js` · ✨ = ของใหม่

```
เริ่มไฟต์
  1 ร่างพิเศษ (🌍 องศา)
  2 setup (🐭 ขโมยสเตตัส)
  3 ออร่า ทีม A แล้ว B (🐳 🦭 🦁 🧚 🦇 🐺 🐢 ☀️ 🦉) + ประกาศฤดู 🌍
  4 initHunt (🦖 จับฐานพลังโจมตี)
  5 onStart (🐉 พ่นไฟเปิด) — ฆ่าได้ก่อนรอบ 1
  6 ✨ ช่องซัพพอร์ต: ออร่าของซัพพอร์ตใส่ตรงขั้น 3 (§4)
  ทีมไหนตีก่อน: 🐹 ช่อง 1 > ตัวเยอะกว่า > สุ่ม

ต้นรอบ (onRound) — ทีม A ทั้งทีม แล้วทีม B · ในทีมไล่ช่องซ้ายไปขวา
  - ☀️ บัฟร้อนจากจบรอบก่อนเริ่มมีผล
  - 💧 คู่หู 🦭🐳 ฟื้นเลือด · 🐍 🐘 🐼 ฟื้นตัวเอง · 🦋 ฟื้นเพื่อน · 🐍 พลังโจมตีขึ้น
  - ✨ 🛸 ดูดเป้า (ถ้ายังไม่ได้ดูดใครอยู่)
  - ✨ ซัพพอร์ตแบบต้นรอบ (🦋 ☄️ ถ้าอยู่ช่องซัพพอร์ต)

ตา (สลับฝั่งทีละตา · ในทีมไล่ช่องซ้ายไปขวา)
  ✨ ต้นตา (hook ใหม่ onTurnStart) ตามลำดับนี้:
     a. สถานะร้ายแบบ "ทำดาเมจต่อตา" ทำงาน (เผาไหม้ในอนาคต) — ตายตรงนี้ = ไม่ได้ตา
     b. ❄️ แช่แข็ง/ข้ามตา → จบตา (นับว่าได้ตาแล้ว)
     c. ✨ 👻 วิญญาณนับตาถอยหลัง · 🗿 นับตาหลับ
     d. ✨ ☄️ ให้พร
     e. 👹 ง้าง → จบตา
  โจมตี:
     onAttack (เลือกเป้า/ตัวคูณ) → คริ/ธาตุ/สุ่ม → หมัด
     onHit ฝั่งผู้รับ: 🐘 รับแทน → 🐢 ลดทั้งทีม → 🦍 ลดจากการยั่วยุ → ✨ 🤖 ลดตามสาย → ✨ 🗿 ลด 50% ขณะหลับ
                      → ✨ ☄️ โล่พร 30% → 🦊 หลบ / 🦔 หนาม / 🦣 เกราะ → 🦍 สะสมพลัง → 🦠 เชื้อ
     onDealt ฝั่งผู้ตี: 🦄 ฟื้นเพื่อน · 🦇 ดูดเลือด
     ตาย: 🐱 → 🐦‍🔥 (+หมัดสวน) → 🧞 → ✨ 👻 เป็นวิญญาณ → 🎃 · แล้ว onAnyDeath (🦠 ย้ายเชื้อ)

     ✨ หลังหมัดจบ: 👽 ควบคุมจิตใจ (หมัดลูก) → 🛸 นับครั้งที่โดน / ปล่อยตัว

  - 🌍 ฤดู (ร้อนตั้งบัฟรอบหน้า · ฝนฟื้น · หนาวแช่แข็ง)
  - ไฟไหม้/น้ำพุประจำสัปดาห์
```

**กติกาของรอบที่ของใหม่ต้องเคารพ**
- ตัวที่ถูกดูด (🛸) = ไม่อยู่ในรอบ เหมือนตัวที่ตาย → รอบไม่รอมัน · ถูกปล่อยกลางรอบ = เริ่มได้ตารอบถัดไป
- 👻 วิญญาณ = อยู่ในรอบ (ได้ตา) แต่ไม่นับว่า "ยังมีชีวิต" ตอนตัดสินแพ้ชนะ
- หมัดลูก (หมัดสวน 🐦‍🔥 · หมัดควบคุม 👽 · ตกกระแทก 🛸) อยู่ในจังหวะเดิม ไม่เพิ่มจังหวะ (กฎเหล็กเดิม)
- งานที่ทั้งสองทีมทำพร้อมกัน (ต้นรอบ/จบรอบ) ทีม A ก่อนเสมอ (เหมือนเดิม) — มีผลจริงแค่เคส 🛸 ปะทะ 🛸 (§2.1)

## 2. สกิลรายตัว

### 2.1 🛸 ยูเอฟโอ — ✊ (ไอเดีย user)

**ร่างข้อความการ์ด**
> ต้นรอบ ถ้ายังไม่ได้ดูดใคร ดูดศัตรูที่พลังโจมตีสูงสุด 1 ตัวออกจากสนาม (ไม่ได้ตา ถูกโจมตีไม่ได้ สกิลหยุดทำงาน) · ระหว่างดูด ยูเอฟโอสร้างดาเมจ {pct}% · ยูเอฟโอถูกโจมตีครบ {hits} ครั้ง หรือครบ {rounds} รอบ จะปล่อยตัวนั้นกลับ และตัวนั้นเสียเลือด {drop}% ของเลือดสูงสุด
>
> short: `ดูดศัตรูแรงสุดออกจากสนาม · โดนตี {hits} ครั้งปล่อย + ตกกระแทก {drop}%`

ค่าตั้งต้นเสนอ: pct 50 · hits 3 · rounds 2 · drop 30

**จุดที่ต้องเคาะ**
1. **"2–4 ครั้ง" แปลว่าอะไร** — (ก) สุ่มทุกครั้งที่ดูด · (ข) ตามขั้นสกิล Lv1=4 → Lv.MAX=2 · ผมเสนอ (ข) เพราะการ์ดบอกเลขได้ตรงๆ
   ⚠️ ถ้าใช้ (ข) "ครั้งน้อยลง" = ปล่อยเร็วขึ้น = ตกกระแทกถี่ขึ้น แต่ศัตรูได้ตัวคืนเร็วขึ้น — ขั้นสูงไม่ได้แรงขึ้นตรงๆ ต้องลองซิม
2. **ต้องมีเพดานเวลา (เสนอ 2 รอบ)** — เป้าโจมตีเป็นการสุ่ม ศัตรูเหลือ 2 ตัวบนสนาม สุ่มโดนยูเอฟโอราว 1 ใน 3 ⇒ ได้แค่ ~0.7 ครั้ง/รอบ
   ครบ 3 ครั้งใช้ ~4 รอบ (ไฟต์ส่วนใหญ่จบก่อน) · ถ้าฝั่งเรามี 🦍 ยั่วยุ ศัตรูไม่ตียูเอฟโอเลย = ดูดค้างตลอดไฟต์
3. **ดูดใคร** — เสนอ "พลังโจมตีสูงสุด เท่ากันเอาช่องซ้าย" (ไม่ดึงสุ่ม · ผู้เล่นเดาได้ · ตามสเปกเดิม "ดูดตัวที่แรงที่สุด")
4. **ปล่อยแล้วดูดใหม่เมื่อไหร่** — เสนอ: ต้นรอบถัดไปดูดใหม่ได้ทันที (ตามข้อความ "ถ้ายังไม่ได้ดูดใคร") · ถ้าแรงไปค่อยเพิ่มพัก 1 รอบ

**กติกาที่ต้องเขียนลงเอนจิน (ไม่ต้องใส่การ์ดทั้งหมด)**
- ตัวที่ถูกดูด: ไม่ได้ตา · ไม่ถูกเลือกเป็นเป้าของอะไรเลย (หมัด/ลาม/🐉/🦠 แพร่/❄️/👽) · สกิลหยุด (🐘 ไม่รับแทน · 🦍 ไม่ยั่วยุ · 🦋 ไม่ฟื้น · 🧞 ไม่กันตาย)
  ยกเว้น **ออร่าที่ใส่ไปตอนเริ่มไฟต์ยังอยู่** (ห้ามแก้เลือดสูงสุดกลางไฟต์ — กฎเดิมใน petPassives.js)
- สถานะร้ายที่ติดอยู่ (❄️ 🦠 🤍) ค้างไว้ ไม่ลด ไม่ทำงาน
- "ถูกโจมตี 1 ครั้ง" = ทุกหมัดที่โดน **รวมหมัดลูก** (🐲 ลาม · 🐕 · 🤍 ตีซ้ำ) ไม่นับ หนาม/สะท้อนเกราะ/เชื้อ/🐉 พ่นไฟเปิด · หลบได้ = ไม่นับ
  ⇒ 🐰 🐕 เป็นตัวแก้ทาง (ตรงกับบอสโล่นับครั้งในดันหิน — ผู้เล่นเรียนรู้ครั้งเดียวใช้ได้สองที่)
- ตกกระแทก = ไม่ใช่หมัด · หลบไม่ได้ · ไม่ผ่านการลดดาเมจ · ฆ่าได้ (ผู้ฆ่า = ยูเอฟโอ → 🐱 🧞 🐦‍🔥 ยังทำงาน)
  ⚠️ "ไม่ผ่านการลด" ไม่ชนกฎ "ทะลุการป้องกันเป็นของไวรัสตัวเดียว" เพราะเป็นดาเมจ % เลือดตายตัว ไม่ใช่ดาเมจโจมตี (เหมือน 🐉) — ถ้า user อยากให้ 🐢 ลดได้ บอกได้
- **ยูเอฟโอตาย** = ปล่อยตัวทันที ไม่มีตกกระแทก
- **ศัตรูบนสนามตายหมด เหลือแต่ตัวที่ถูกดูด** = ปล่อยทันที (มีตกกระแทก) แล้วสู้ต่อ — ไม่งั้นไฟต์ค้างจนชน maxTurns
- 🛸 ปะทะ 🛸: ทีม A ดูดก่อน · ถ้าดูดยูเอฟโอฝั่ง B ไป = ฝั่ง B ไม่ได้ดูด (ตัวที่ B ดูดไว้ก่อนหน้าถูกปล่อย ไม่มีตกกระแทก)
- ช่อง "ดาเมจ 50%" คูณเฉพาะหมัดของยูเอฟโอเอง

**เอนจิน:** แนวคิดใหม่ "นอกสนาม" — `onField(u) = hp > 0 && !ps.away` · ต้องไล่เปลี่ยน `alive()` ที่ใช้ "เลือกเป้า/หาเพื่อน" เป็น `onField()` ทั้งไฟล์ แต่ตอนตัดสินแพ้ชนะยังใช้ hp
(งานใหญ่ที่สุดของชุดนี้ · ใช้ซ้ำกับ 👻 ได้)

### 2.2 ☄️ ดาวหาง — ✌️ (ไอเดีย user)

**ร่างข้อความการ์ด**
> ต้นตาของดาวหาง ให้พรเพื่อน 1 ตัว (รวมตัวเอง): ล้างสถานะร้ายทั้งหมด · ฟื้นเลือด {heal}% ของเลือดสูงสุด · ดาเมจจากการโจมตีครั้งถัดไปที่ได้รับลดลง {shield}% (ไม่สะสม · อยู่จนกว่าจะถูกโจมตี)
>
> short: `ต้นตา: พรเพื่อน 1 ตัว ล้างสถานะ · ฟื้น {heal}% · กันครั้งถัดไป {shield}%`

**จุดที่ต้องเคาะ**
1. **สุ่มล้วนอ่อนไปสำหรับตำนาน** — 🦋 ผีเสื้อ (ธรรมดา) ฟื้น 20% ให้ "ตัวที่เลือดน้อยสุด" ทุกต้นรอบอยู่แล้ว · ดาวหางสุ่มตกตัวเลือดเต็มไม่มีสถานะ = พรเปล่า
   เสนอวิธีเลือก: **ตัวที่มีสถานะร้ายก่อน → ไม่มีก็ตัวที่ % เลือดน้อยสุด** (ไม่ดึงสุ่ม อ่านการ์ดแล้วรู้ว่าใครจะได้)
   ถ้าอยากคงความสุ่มไว้เป็นเสน่ห์ → ต้องขึ้นฟื้นเป็น 30% หรือให้พร 2 ตัว
2. **ต้นตาตัวเอง หรือ ต้นรอบ** — "ต้นตาตัวเอง" ตามที่เล่า: โดนแช่แข็ง = เสียตา = ไม่ได้ให้พรด้วย (ล้างแช่แข็งตัวเองไม่ได้)
   ต้นรอบ: ทำงานก่อนทุกคน แต่ล้างแช่แข็งที่ 🌍 แปะตอนจบรอบได้ทุกครั้ง (แรงกว่า) · ผมเสนอ **ต้นตา** ตามเดิม แต่ให้พรทำงานก่อนเช็คแช่แข็ง ถ้าพรตกตัวเอง (ลำดับ d ก่อน b ใน §1 เฉพาะกรณีนี้) — หรือเรียบกว่า: ต้นตา โดนแช่ก็เสียพร (ผมโอเคทั้งคู่)

**กติกา**
- "สถานะร้าย" นิยามที่ §3 · ไม่รวมออร่าศัตรู (🦉 รับดาเมจเพิ่ม · 🐭 ถูกขโมยสเตตัส) และไม่ดึงตัวที่ถูก 🛸 ดูดกลับ
- โล่พร: ใช้หมดกับ **หมัดแรกที่โดนจริง** (หลบได้ = ยังอยู่ · 🦣 เกราะกันทั้งหมัด = ยังอยู่) · หมัดลูก 🐰 🐕 ตัวแรกใช้หมด
  ไม่ลดหนาม/สะท้อน/ตกกระแทก/เชื้อ · ได้พรซ้ำตอนมีโล่อยู่ = ฟื้น+ล้างตามปกติ โล่คงเป็น 1
- คู่กับ 🦄 (ล้างอย่างละ 1 ตอนตี) ไม่ชนกัน

### 2.3 👽 เอเลี่ยน — ✌️ (ไอเดีย user)

**ร่างข้อความการ์ด**
> เมื่อโจมตีโดน เป้าถูกควบคุมจิตใจ โจมตีเพื่อนร่วมทีมของตัวเอง 1 ตัวแบบสุ่ม (รวมตัวเอง) ทันที {pct}% ของพลังโจมตีของเป้า · ใช้พลังที่สะสมไว้ ณ ตอนนั้นโดยไม่ทำให้หมด · สกิลของเป้าไม่ทำงานในหมัดนี้
>
> short: `ตีโดนแล้ว เป้าตีพวกเดียวกัน {pct}% (สุ่ม)`

ค่าตั้งต้น: pct 60

**นิยาม "พลังที่สะสมไว้" (สำคัญที่สุดของตัวนี้ — ต้องเป๊ะ)**

| นับ (อ่านค่าอย่างเดียว ไม่ใช้หมด ไม่สะสมเพิ่ม) | ไม่นับ (สกิลที่ทำงานตอนตี) |
|---|---|
| พลังโจมตีบนการ์ดทั้งหมด: ออร่า · 🦖 ชั้นล่า · 🦍 ชั้นโกรธ · 🐍 ชั้น · 🐱 บัฟทนต่อ · ☀️ บัฟร้อน | 🦖 ไม่ได้ชั้นเพิ่ม · 🌙 ข้างจันทร์ไม่ขยับ |
| 🌙 ข้างจันทร์ปัจจุบัน (เต็มดวง = ×325%) | 🐲 🐕 ลาม · 🐰 แปะมาสก์/ตีซ้ำ · 🦠 แปะเชื้อ/ระเบิด · 🦄 ฟื้น · 🦇 ดูดเลือด |
| 👹 ถ้ากำลังง้างค้าง = ฟาด ×300% แต่ยังง้างค้างอยู่ | 🦈 🐗 🦡 🐹 🦅 ตัวคูณตามเงื่อนไข · คริ · ธาตุ (คิดกลางๆ) |

⚠️ เคส 👹: 60% × 300% = **180% ของพลังโจมตีโอนิใส่เพื่อนตัวเอง** — แรงมาก แต่เป็นสิ่งที่ user ตั้งใจ ("ตีแรง") · เป็นตัวแก้ทางทีมสะสม ถือว่าดี

**กติกาฝั่งตัวที่โดนหมัดควบคุม**
- หลบ 🦊 / ลด 🐢 🤖 🗿 / โล่พร ☄️ / เกราะ 🦣 (กันได้แต่ **ไม่สะท้อน**) / 🐘 รับแทน — ทำงานปกติ
- **ไม่สะท้อน ไม่สะสม**: 🦔 หนามไม่สวนเพื่อน · 🦣 ไม่สะท้อน · 🦍 ไม่ได้ชั้นโกรธ (กันฟาร์มชั้นจากเพื่อน)
- 🦉 รับดาเมจเพิ่มของนกฮูก (ถ้านกฮูกอยู่ทีมเอเลี่ยน) คิดตามปกติ — เป็นของตัวผู้รับ
- ผู้ฆ่า = **เอเลี่ยน** (ไม่ใช่ตัวที่ถูกควบคุม) ⇒ 🐦‍🔥 ฟื้นแล้วสวนเอเลี่ยน ไม่สวนเพื่อนตัวเอง
- ไม่ทำงานถ้า: เป้าตายจากหมัดเอเลี่ยน · เป้าหลบ · เอเลี่ยนตัวนั้นเองถูกควบคุมอยู่ · เป้าถูกดูด/หลับ 🗿 (ไม่ขยับ)
- เป้าโดนแช่แข็งอยู่ = ยังถูกควบคุมได้ (ไม่ใช่ตาของมัน ไม่ลดสแตคแช่)
- 1 ตาเอเลี่ยน = ควบคุม 1 ครั้ง (ถ้าวันหน้าได้หมัดลาม เช่นจากเทวภัณฑ์ ก็ยังครั้งเดียว)

### 2.4 🤖 หุ่นยนต์ — ✋ (ร่าง จากสเปกเดิม)

> ถูกโจมตีโดยศัตรูสายใด รับดาเมจจากสายนั้นลดลง {pct}% สะสม แยกตามสาย (สูงสุด {max}%)
>
> short: `ถูกสายไหนตี ลดดาเมจจากสายนั้น +{pct}% (สูงสุด {max}%)`

ค่าเสนอ: pct 10 · max 40 · step pct +2 / max +5

- คิดหลังได้รับหมัด (หมัดแรกจากสายนั้นยังเต็ม) · หลบได้ไม่นับ · หมัดลูกนับทุกครั้ง (🐰 🐕 ทำให้มันแข็งเร็ว — ทางแพ้ทางที่ตั้งใจ)
- ลดเป็นทอด ×(1−p) ต่อจาก 🐢 ไม่บวก % (กฎเดิม)
- **ทำไมเหมาะกับคอนเทนต์ฟาร์ม:** บอสดันหินเป็นสายเดียว ⇒ หุ่นยนต์เป็นแทงก์ดันเจี้ยนที่ดีที่สุด แต่ใน PvP ทีมผสม 3 สายจะอ่อนลง — แรงคนละที่ ไม่ครองทุกโหมด
- ไม่ชนตัวไหน: 🐢 ลดตายตัว · 🦣 กันครั้ง · 🦊 หลบ · 🤖 = ลดที่โตระหว่างไฟต์

---

### 2.5 👻 ผีน้อย — ✋ (ร่างที่เสนอไว้ 26 ต.ค.)

> เมื่อตาย กลายเป็นวิญญาณ {turns} ตา: โจมตีได้ตามปกติ ศัตรูโจมตีไม่ได้ จากนั้นหายไป · ทีมที่เหลือแต่วิญญาณถือว่าแพ้
>
> short: `ตายแล้วเป็นวิญญาณ ตีต่อ {turns} ตา (ศัตรูตีไม่ได้)`

ค่าเสนอ: turns 2 · step 0 (ขั้นสูงเพิ่มดาเมจตอนเป็นวิญญาณแทน เช่น +0/+15/+30%)

- เป็นวิญญาณ **หลัง** กันตายทุกแบบไม่ทำงานแล้ว (🧞 กันได้ = ยังไม่ตาย ยังไม่เป็นวิญญาณ) · นับเป็นการตายจริง (🦠 ย้ายเชื้อ · 🦖 · 🎃 ทำงาน)
- วิญญาณ: ไม่ถูกเลือกเป็นเป้า (ใช้ "นอกสนาม" ของ 🛸 ซ้ำได้ครึ่งหนึ่ง) · ไม่ติดสถานะร้าย · ไม่ถูก 🛸 ดูด/👽 ควบคุม · ไม่ได้รับฟื้นเลือด
- นับตาที่ต้นตา (§1 ขั้น c) · ครบแล้วหายไป
- **ทำไมเลือกแบบนี้ ไม่ใช่หลบ:** หลบมี 🦊 กับ 👻มอนดันเจี้ยนแล้ว 2 ตัว
- แผนสำรองถ้าเอนจินไม่ทัน: "เมื่อตาย สาปผู้ที่ทำให้ตาย: ดาเมจที่ทำ −30% จนกว่าจะถูกล้าง" (ใช้ระบบสถานะ §3 · ล้างได้ด้วย ☄️ 🦄)

---

### 2.6 🗿 โมอาย — ✊ (ร่าง ปรับจากที่เสนอไว้)

> สลับวงจร 3 ตา: 2 ตาแรกหลับ (ไม่โจมตี · รับดาเมจ −{dr}% · เก็บดาเมจที่ได้รับ) · ตาที่ 3 ตื่น โจมตีเพิ่มเท่ายอดที่เก็บ (สูงสุด {cap}% ของพลังโจมตี) แล้วเริ่มหลับใหม่
>
> short: `หลับ 2 ตา เก็บดาเมจ (−{dr}%) · ตาที่ 3 ตีเพิ่มเท่ายอดที่เก็บ`

ค่าเสนอ: dr 50 · cap 300

- ร่างเดิม "หลับ 3 รอบ" ยาวไป — ไฟต์ส่วนใหญ่ 4–6 รอบ = ตื่นได้ครั้งเดียว · ย่อเป็นวงจร 3 ตา อ่านง่ายเหมือน 👹 (ง้าง/ฟาด)
- หมัดตื่น = พลังโจมตีปกติ + ยอดที่เก็บ (ผ่านการลดของเป้าตามปกติ · ไม่คริ) · ยอดเก็บ = เลือดที่หายจริงหลังลด
- ระหว่างหลับ: แช่แข็งยังกินตา (ตาที่ถูกข้ามนับเป็นตาหลับ) · 👽 ควบคุมไม่ได้ · หลับ "ไม่ใช่สถานะร้าย" ☄️ ล้างไม่ได้
- ตัวแก้ทาง: 🦍 ยั่วยุฝั่งตรงข้ามดึงหมัดไปที่ตัวเอง = โมอายเก็บไม่ได้ (ดีกับเกม)
- คอนเทนต์ฟาร์ม: บอสง้างท่า (ดันหินตัวที่ 3) ต้องทำดาเมจถึงเกณฑ์ — หมัดตื่นของโมอายเป็นทางทำถึงเกณฑ์อีกทาง นอกจาก 🦈 🦡 🐗

---

### 2.7 สมดุลเบื้องต้น (ยังไม่ซิม)

- น่าห่วงสุด: **🛸** (ลบศัตรู 1 ใน 3 ออกจากสนาม = เกมกลายเป็น 3v2) — ต้องมีเพดานรอบ และให้ดูดแค่ต้นรอบ
- รองลงมา: **👽** กับทีมพลังโจมตีสูง (🦖 ปลายไฟต์ · 👹 ง้างค้าง) — ตั้งใจให้เป็นตัวแก้ทาง
- อ่อนที่สุดถ้าไม่ปรับ: **☄️** แบบสุ่มล้วน
- ก่อนปล่อยจริง: ซิมเล็ก (ตารางปะทะ 6 ตัวใหม่ × ทีมเมต้าเดิม) ไม่ต้องซิมใหญ่

## 3. ระบบสถานะ (รองรับ เผาไหม้/กัดกร่อน ในอนาคต)

### ของที่มีวันนี้ (ต่างคนต่างเก็บ)
| สถานะ | เก็บที่ | ลดลงเมื่อ | ล้างได้โดย |
|---|---|---|---|
| ❄️ แช่แข็ง | `ps.skip` (สแตค) | ถึงตาตัวเอง −1 | 🦄 −1 |
| 🦠 ติดเชื้อ | `ps.infect {n, from}` | ไม่ลด (ย้ายตอนตาย) | 🦄 −1 |
| 🤍 มาสก์ประกาย | `ps.spark` | ไม่ลด | 🦄 −1 |

`🦄` ล้างได้เพราะเขียนชื่อสามอันนี้ไว้ตรงๆ ในโค้ด — **วันที่มีสถานะที่ 4 ยูนิคอร์นจะไม่รู้จักมัน**

### เสนอ: ทะเบียนสถานะกลาง `data/statuses.js`
```js
burn: { kind: 'debuff', icon: '🔥', name: 'เผาไหม้',
        stack: 'add', max: 5,            // add = ซ้อนชั้น · refresh = ต่ออายุ · none = มีได้อันเดียว
        tick: 'turnStart',               // ทำงานต้นตาของตัวที่ติด (อ่านง่าย เห็นบนการ์ดตัวที่กำลังจะตี)
        decay: 1,                        // ลดกี่ชั้นต่อครั้งที่ทำงาน (0 = ไม่ลดเอง)
        cleanse: true },
```
- เก็บรวมที่ `ps.status[id] = { n, from }` · ย้าย ❄️ 🦠 🤍 เข้าทะเบียน (คงพฤติกรรมเดิมเป๊ะ — เทสเดิมคุม)
- ฟังก์ชันกลาง `cleanseAll(unit)` (☄️) · `cleanseOne(unit)` (🦄 อย่างละ 1) — อ่านจากทะเบียน ไม่เขียนชื่อสถานะในตัวยูนิคอร์นอีก
- **3 กลุ่มที่ต้องแยกให้ชัด (ใส่ในคู่มือผู้เล่นด้วย):**
  - **สถานะร้าย** (ล้างได้): ❄️ 🦠 🤍 + 🔥 เผาไหม้ · 🧪 กัดกร่อน ในอนาคต
  - **สถานะดี** (ล้างไม่ได้ ไม่ใช่ของร้าย): ☄️ โล่พร · 🐱 ทนต่อ · 🏏 ง้าง
  - **ไม่ใช่สถานะ** (ล้างไม่ได้): ออร่า 🦉 · ถูกดูด 🛸 · หลับ 🗿 · วิญญาณ 👻 · ยั่วยุ 🦍
- ร่างสถานะอนาคต (ยังไม่ใส่เพ็ทไหน · ใช้กับบอสดันหิน "พ่นสถานะทุกจบรอบ" ก่อน):
  - 🔥 **เผาไหม้**: ต้นตา เสียเลือด X% ของเลือดสูงสุดต่อชั้น แล้วลด 1 ชั้น · ฆ่าได้
  - 🧪 **กัดกร่อน**: รับดาเมจเพิ่ม X% ต่อชั้น · ไม่ลดเอง (ต้องล้าง) — เป็นคู่ของ 🦉 แต่รายตัวและล้างได้
  - 💫 **มึน**: ข้ามตา 1 (ใช้ช่อง skip เดียวกับแช่แข็ง แต่ชื่อ/ไอคอนต่าง) — สำหรับบอสง้างที่ถูกตัดท่า
- บอส "ต้านทานบัฟ/สถานะ": ฟิลด์ `resist: ['freeze', ...]` บนมอน (ทะเบียนเดียวกันเช็คก่อนแปะ) · `immune: ['away']` = ดูดไม่ได้ (บอสต้องกัน 🛸 ไม่งั้นไฟต์บอสพัง)

## 4. ช่องซัพพอร์ต (แนว 7DS · ไม่หมุนลงสนาม)

**แนวคิด:** ทีม = 3 ช่องสนาม + 1 ช่องซัพพอร์ต · ตัวในช่องซัพพอร์ตไม่ลงสนาม ไม่ตี ไม่ถูกตี ไม่นับในทีม — ให้แค่ **"สกิลซัพพอร์ต"** ถ้ามี

**กติกาเสนอ**
- เพ็ทแต่ละตัวมีช่อง `support` ในข้อมูลของตัวเอง (มีหรือไม่มีก็ได้) · การ์ดแสดงบรรทัดแยก `ซัพพอร์ต: …` · ไม่มี = ใส่ช่องนี้ไม่ได้
- **ค่าซัพพอร์ตแยกจากค่าบนสนาม** (เสนอราวครึ่งหนึ่ง) — ไม่งั้นทุกทีมได้ออร่าตัวที่ 4 ฟรี = เพิ่มพลังทั้งเกม หอคอย/ดันต้องจูนใหม่
- ช่องซัพพอร์ต **ไม่นับ** ใน: 🦁 ครบ 3 สาย · 🐺 หมาป่าเดียวดาย · 🦭 คู่ 🐳 (เสนอไม่นับ) · จำนวนตัวตอนเลือกว่าใครตีก่อน
- ปลดล็อกตามเลเวลบ้าน (เป็นเป้าหมายระยะกลางให้ผู้เล่นเก่า)

**ตัวที่ใส่ซัพพอร์ตได้ (ร่าง)**

| ตัว | สกิลบนสนาม | ซัพพอร์ต (ร่าง) |
|---|---|---|
| 🐳 คุณวาฬ | ทีมเลือด +15% | ทีมเลือด +8% |
| 🦭 แมวน้ำ | ทีมพลังโจมตี +6% (+คู่) | ทีมพลังโจมตี +4% (ไม่มีคู่) |
| 🧚 ภูต | ทีมคริ +15% | ทีมคริ +8% |
| 🦇 ค้างคาว | ทีมดูดเลือด 15% | ทีมดูดเลือด 8% |
| 🐺 หมาป่า | สายจู่โจม พลังโจมตี +15% | สายจู่โจม +8% |
| 🐢 เต่า | ทีมลดดาเมจ 18% (ตัวเอง ×2) | ทีมลดดาเมจ 9% |
| ☀️ ซอล | บัฟตามระดับ | ครึ่งหนึ่งของแต่ละระดับ |
| 🦉 นกฮูก | ศัตรูรับดาเมจ +12% | ศัตรูรับดาเมจ +6% |
| 🦋 ผีเสื้อ | ต้นรอบฟื้นเพื่อนเลือดน้อยสุด 20% | ต้นรอบฟื้น 10% |
| 🧞 จินนี่ | กันเพื่อนตาย 1 ครั้ง | (เสนอไม่ให้ — กันตายฟรีโดยไม่มีตัวให้ฆ่าแรงเกิน) |
| ☄️ ดาวหาง | ต้นตา ให้พร | ต้นรอบ ให้พร (ฟื้น 10% · โล่ 15%) |
| 🦁 สิงโต | ครบ 3 สาย บัฟทีม | ครบ 3 สายบนสนาม บัฟครึ่งหนึ่ง |

ใส่ไม่ได้ (ต้องมีตัวอยู่บนสนาม): ทุกตัวที่ตี/โดนตีถึงทำงาน (🐘 🦍 🦣 🦄 🦖 🌙 👹 🦠 …) · 🌍 (ผลขึ้นกับช่อง) · 🐭 (setup ขโมยสเตตัส — แรงเกินถ้าฟรี) · 🐹

⚠️ ต้องเคาะ: ซัพพอร์ตใช้ใน PvP/หอคอย/ดันทั้งหมด หรือเฉพาะบางโหมด (เสนอทุกโหมด แต่บอสดันต้านทานได้บางอย่าง)

## 5. ทางยาว: ดันหิน · ห้องเรียลไทม์ · เทวภัณฑ์

- **ดันหินสกิล** (แผน 18 ต.ค.): บอส 3 แบบรับกับตัวใหม่พอดี — โล่นับครั้ง (🐰 🐕 · ทำให้ 🤖 แข็ง) · พ่นสถานะ (☄️ 🦄 🦋) · ง้างท่า (🗿 🦈 🦡 🐗 · ❄️ ตัดท่า)
  บอสต้องมี `immune: ['away', 'control']` (กัน 🛸 ดูด/👽 ควบคุม — บอสตัวเดียว ถ้าโดนดูดไฟต์ว่าง)
- **ห้องฟาร์มร่วม (RTDB)**: เอนจินต้อง deterministic อยู่แล้ว (สุ่มผ่าน rand เดียว) — ของใหม่ทุกตัวในเอกสารนี้ **ห้ามดึงสุ่มนอก rand** · 🛸 เลือกเป้าแบบไม่สุ่ม · ☄️ เสนอแบบไม่สุ่ม
- **เทวภัณฑ์** (ชื่อชั่วคราว · อนาคตไกล): ของประจำตัวเพ็ท ให้สกิลเพิ่ม 1 อย่าง · เตรียมรูปข้อมูลไว้ตอนนี้ได้เลยโดยไม่เสียอะไร —
  เทวภัณฑ์ = `parts` ชุดเพิ่มที่ต่อท้าย parts เดิม (ระบบ parts รองรับหลายผลอยู่แล้ว) + บรรทัดคำอธิบายของตัวเอง
  ⚠️ กฎที่ต้องวางตั้งแต่ตอนนี้: เทวภัณฑ์ "เพิ่มผลใหม่" ไม่ใช่ "คูณเลขของเดิม" — ไม่งั้นชนกับขั้นสกิลจากดันหิน (โตสองทางทับกัน)

## 6. รีไรต์คำอธิบายสกิลทุกตัว

**หลักการ (ต่อจาก CLAUDE.md ข้อ 16):** ข้อความแบบการ์ดเกม — ครบตามโค้ด · ไม่ใส่ความรู้สึก · ใช้คำซ้ำชุดเดียวกันทั้งเกม · กิมมิคที่ตั้งใจซ่อนคงไว้ซ่อน

**คำมาตรฐาน (ใช้คำเดียวทั้งเกม)**
- เวลา: `เริ่มการต่อสู้:` · `ต้นรอบ:` · `ต้นตา:` · `จบรอบ:` · `เมื่อโจมตี:` · `เมื่อถูกโจมตี:` · `เมื่อตาย:`
- เป้า: `ตัวเอง` · `เพื่อน` (ไม่รวมตัวเอง) · `ทั้งทีม` (รวมตัวเอง) · `ศัตรู 1 ตัว` · `ศัตรูทุกตัว`
- ค่า: `พลังโจมตี` · `เลือดสูงสุด` · `ดาเมจ` (ของหมัดนั้น) · `% ของพลังโจมตี`
- ดาเมจพิเศษ: `ไม่ถูกลดและหลบไม่ได้` (ใช้กับ 🐉 🦠 🛸)

### ร่างข้อความใหม่ทั้งหมด (desc · ตัวเลขยังเป็น {ตัวแปร} ตามกฎ)

**ตำนาน**
- 🐉 บาฮามุท — เริ่มการต่อสู้: สร้างดาเมจ {pct}% ของพลังโจมตีใส่ศัตรูทุกตัว ไม่ถูกลดและหลบไม่ได้
- 👹 โอนิ — สลับทุกตา: ตาง้าง (ไม่โจมตี) → ตาฟาด {pct}% ของพลังโจมตี · ฟาดแล้วศัตรูตาย ฟาดต่ออีก 1 ครั้ง · ตาแรกของการต่อสู้เป็นตาง้าง
- 🦖 ทีเร็กซ์ — เมื่อโจมตี: ก่อนคิดดาเมจ พลังโจมตี +{pct}% ของพลังโจมตีตั้งต้น สะสมไม่จำกัด · เริ่มการต่อสู้พร้อม {start} ชั้น
- 🐍 อูโรโบรอส — ต้นรอบ: ฟื้นเลือดตัวเอง {regen.pct}% ของเลือดสูงสุด · พลังโจมตี +{rage.pct}% (สูงสุด {rage.max} ชั้น)
- 🦅 กริฟฟิน — โจมตีศัตรูที่ % เลือดเหลือน้อยที่สุด (ถูกยั่วยุ = ตีตัวที่ยั่วยุ) · ดาเมจ +% เท่ากับ % เลือดที่เป้าเสียไป
- 🐦‍🔥 ฟีนิกซ์ — เมื่อตายครั้งแรก: ฟื้นด้วยเลือด {pct}% ของเลือดสูงสุด และโจมตีตัวที่ทำให้ตาย {counterPct}% ของพลังโจมตี
- 🐳 คุณวาฬ — ทั้งทีม เลือดสูงสุด +{pct}%
- 🐘 บากุ — เมื่อเพื่อนถูกโจมตี: รับดาเมจแทน {guard.pct}% ของหมัดนั้น · ต้นรอบ: ฟื้นเลือดตัวเอง {regen.pct}% ของเลือดสูงสุด
- 🦁 สิงโต — เริ่มการต่อสู้: ถ้าทีมมีครบ 3 สาย ทั้งทีมพลังโจมตี +{pct}% และเลือดสูงสุด +{hpPct}%
- 👾 ไวรัส — เมื่อโจมตี: ศัตรูทุกตัวติดเชื้อ +1 ชั้น (ไม่จำกัด) · ทั้งทีมโจมตีศัตรูที่ติดเชื้อ ได้ดาเมจเพิ่มชั้นละ {pct}% ของพลังโจมตีไวรัส ไม่ถูกลดและหลบไม่ได้
- 🦍 กอริลลา — ศัตรูต้องเลือกกอริลลาเป็นเป้าหลัก · ดาเมจจากหมัดนั้น −{taunt.pct}% · เมื่อถูกโจมตี: พลังโจมตี +{rage.pct}% สะสมไม่จำกัด
- 🦣 แมมมอธ — เริ่มการต่อสู้พร้อมเกราะ {count} ชั้น · เมื่อถูกโจมตี: ใช้เกราะ 1 ชั้นกันหมัดนั้นทั้งหมด และสะท้อน {pct}% ของดาเมจนั้นใส่ศัตรูทุกตัว
- ☀️ ซอล — เพื่อน พลังโจมตีและเลือดสูงสุดเพิ่มตามระดับ: ธรรมดา +{common}% · หายาก +{rare}% · เอพิค +{epic}%
- 🌍 เอิร์ธ — จบรอบ: ผลตามช่องที่วาง · ช่อง 1 ☀️ ทั้งทีมพลังโจมตี +{hot}% ในรอบถัดไป · ช่อง 2 🌧️ ทั้งทีมฟื้นเลือด {rain}% ของเลือดที่เสียไป · ช่อง 3 ❄️ ศัตรูแต่ละตัวมีโอกาส {cold}% ถูกแช่แข็ง 1 ตา

- 🧚 ภูต — ทั้งทีม โอกาสคริติคอล +{pct}%
- 🐼 แพนด้า — ต้นรอบ: ฟื้นเลือดตัวเอง {pct}% ของเลือดสูงสุด

- 🦡 แบดเจอร์ — ดาเมจ +{pct}% เมื่อเป้ามีเลือดสูงสุดมากกว่าตัวเอง

**หายาก**
- 🐺 หมาป่า — สายจู่โจมทั้งทีม (รวมตัวเอง) พลังโจมตี +{pct}% · (หมาป่าเดียวดาย ซ่อนไว้เหมือนเดิม)

## 8. อัปเดตหลังคุยต่อ 26 ต.ค. (ทับข้อที่ขัดกันด้านบน)

### 8.1 ลำดับสกิลที่ทำงานพร้อมกัน = ลำดับตีของโหมดนั้น (user เคาะ)
- PvP: ลำดับที่นั่ง `X1 → Y1 → X2 → Y2 → X3 → Y3` · X = ทีมที่ได้ตีก่อน (🐹 ช่อง 1 → ตัวเยอะกว่า → สุ่ม) ไม่ใช่ A เสมอ
- ใช้กับ setup · ออร่า · เริ่มการต่อสู้ · ต้นรอบ · จบรอบ · ตัวตาย/ถูกดูด = ข้าม ไม่เลื่อนคิว
- ข้อยกเว้น: 🐉 เริ่มการต่อสู้ คิดดาเมจพร้อมกันแล้วค่อยเช็คตาย
- ดันบอส: `P1 ช่อง 1→3 → P2 ช่อง 1→3 → บอส` · บอสออก **1 แอคชั่นต่อรอบ (ฝันร้าย 2)** ไม่ว่าผู้เล่น 3 หรือ 6 ตัว
- เขียนเป็น "รายการที่นั่ง" ไม่ผูกทีม A/B

### 8.2 🤖 หุ่นยนต์ (แทน §2.4)
> เริ่มการต่อสู้: เลือดสูงสุด +{hp}% · เมื่อถูกโจมตี: รับดาเมจจากสายนั้นลดลง {pct}% สะสม แยกตามสาย (สูงสุด {max}%)
- ปกป้องตัวเองเท่านั้น (ตัด "เข้าขวาง" — จะกลายเป็นตัวใช้ได้กับทุกบอส) · บทบาท = แทงก์ของบอสค้อน

### 8.3 ดันหินสกิล — 3 บอส × 3 ระดับ (ทับแผนบอส 18 ต.ค. และ §5)

1. ข้ามตาทุกแบบใช้ช่องเดียว `st.skip` + `skipName/skipIcon` → ถ้าโดนแช่แข็งกับอย่างอื่นที่ข้ามตาพร้อมกัน ชื่อบนแบนเนอร์จะเป็นของตัวที่แปะทีหลังสุด ตัวแรกหายเงียบ
2. 🦄 ล้างสถานะเขียนชื่อ 3 อย่างไว้ตรงๆ (บรรทัด ~599) → สถานะใหม่ทุกตัวจะล้างไม่ได้
3. ไม่มีช่องต้านทาน/ภูมิคุ้มกันบนบอส
4. ไม่มีกติกากลางเรื่องตายแล้วสถานะเป็นยังไง (ตอนนี้มีแค่ 🦠 ย้ายตอนตาย)
5. ดาเมจจากสถานะไม่มีเจ้าของ → 👻 ผีน้อย / 👤 เนเมซิส หาคนฆ่าไม่ได้

**กติกากลาง (เสนอ)**
- ทะเบียนเดียว `data/statuses.js` · เก็บที่ `ps.status[id] = { n, from, val }`
- **นับตาของตัวที่ติด** รวมตาที่ถูกข้าม
- **ต้นตาทำงานตามลำดับ:** ดาเมจต่อเนื่อง (🔥 ☠️) → ตายตรงนี้ = ไม่ได้ตา → ข้ามตา (❄️ 💫 😱) → ตาปกติ
- **ตาที่ถูกข้าม 1 ตา ลดสถานะข้ามตา "ทุกตัว" ตัวละ 1** (ขยายกติกา ❄️+😱 ของ user ไปทั้งกลุ่ม)
- **แปะซ้ำ:** `add` = บวกชั้น มีเพดาน · `refresh` = เอาตัวที่ยาวกว่า · `none` = แปะซ้ำไม่ได้
- **ค่าดาเมจ** ล็อกตอนแปะ (`val`) ไม่เปลี่ยนตามบัฟทีหลัง
- **ตายจากสถานะ = นับคนแปะเป็นคนฆ่า** (`from`) → 👻 แบร่ใส่คนแปะ · ⚠️ เปลี่ยนจาก §8.9 ที่ให้แบร่ใส่ ATK สูงสุด
- **ตาย = ล้างทุกสถานะ** ยกเว้นที่มีกติกาย้าย (🦠)
- **ล้าง:** ☄️ ล้างสถานะร้ายทุกตัว · 🦄 ลดสถานะร้ายตัวละ 1 · อ่านจากทะเบียนเท่านั้น
- **บอส:** `resist: { burn: 0.5 }` (ลดผล) · `immune: ['away', 'fear']` (ไม่ติดเลย)
- **เอฟเฟกต์ (§8.10):** ตอนติด = ตราเด้ง + เขย่า + แบนเนอร์ **ไอคอน+ชื่อ** · ตอนทำงาน = เขย่า + แบนเนอร์ไอคอนอย่างเดียว

**สถานะพื้นฐาน (เลขคร่าวๆ รอซิม)**
| | สถานะ | ผล | แปะซ้ำ | ลดเมื่อ |
|---|---|---|---|---|
| 🔥 | ลุกไหม้ | ต้นตา เสียเลือด **5% ของเลือดสูงสุด × ชั้น** | add เพดาน 3 | ทำงานแล้ว −1 |
| ☠️ | พิษ | ต้นตา เสียเลือด **30% ATK คนแปะ** (ล็อกค่า) | refresh 3 ตา | ตาละ −1 |
| 💫 | มึน | ข้ามตา | none | ข้ามแล้ว −1 |
| ❄️ | แช่แข็ง | ข้ามตา (ของเดิม) | add | ข้ามแล้ว −1 |
| 😱 | หวาดกลัว | ข้ามตา + เสียเลือด 50% ATK ผี | add | ข้ามแล้ว −1 |
| 💔 | เกราะแตก | รับดาเมจ **+15% × ชั้น** | add เพดาน 3 | ไม่ลดเอง ต้องล้าง |
| 🥀 | อ่อนแรง | ATK **−20%** | refresh 2 ตา | ตาละ −1 |
| 🚫 | ห้ามฟื้น | ฟื้นเลือดไม่ได้ (แก้ทาง 🦭🐳 🦋 🦄 🦇) | refresh 2 ตา | ตาละ −1 |
| 🦠 | ติดเชื้อ | ของเดิม | ของเดิม | ของเดิม |
| 🤍 | มาสก์ประกาย | ของเดิม | ของเดิม | ของเดิม |
- **สถานะดี** (ล้างไม่ได้): ☄️ โล่พร · 💪 ฮึด ATK +20% · 💚 ฟื้นต่อเนื่อง 5%/ตา
- **ไม่ใช่สถานะ:** 🛸 ถูกลักพาตัว · ยั่วยุ 🦍 · ออร่า · ง้าง 👹

**🐉 บาฮามุท พ่นไฟ + ลุกไหม้ (ไอเดีย user กับเพื่อน · เสนอ)**
- เปิดไฟต์ตีทุกตัว **85%** (ลดจาก 100) + ติด 🔥 **2 ชั้น** ทุกตัว
- เป้าเสียรวม 85% ATK + 10% → 5% ของเลือดสูงสุดใน 2 ตาแรก (ตัวถึกเจ็บกว่าเดิม · ตัวบางเท่าเดิม)
- เคยโดนลดเพราะชนะเมต้า 95% → ต้องซิมก่อนปล่อย

- **บอสแบบ 7DS:** หน้ารายละเอียดบอสเขียน "ต้านทาน: …" ให้ผู้เล่นหาเองว่าอะไรไม่กัน · ค่าเริ่มต้นบอส = กันสถานะเกือบทั้งหมด เปิดเฉพาะตัวที่ตั้งใจให้เป็นวิธีปราบบอสตัวนั้น
