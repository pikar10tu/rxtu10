## เป้าหมาย
เกมกระดานแนวเศรษฐี (แผนที่โลก) ฟีลยุคกลางของเกมแนวนี้: ดวงบ้าง ฝีมือบ้าง ไม่ล้มละลายในตาเดียว
**เดโม v1** = ขึ้นเว็บจริง แต่เข้าได้เฉพาะแอดมิน + ผู้ทดสอบที่แอดมินเลือก เพื่อชวนเพื่อนเล่นและจูนกติกา

ขอบเขต v1: ห้อง 2–4 คน (คนจริง + บอทธรรมดา เติมหรือไม่เติมก็ได้) · กติกาครบ · **ไม่มีสมบัติ** · **ไม่แจกเหรียญเว็บ**
นอกขอบเขต v1 (ทำทีหลัง): สมบัติ 4 ช่อง (ดูภาคผนวก A) · กาชา · รางวัลเหรียญ · สถิติในโปรไฟล์ · บอทฉลาด

⚠️ ชื่อ/อาร์ต/ชื่อการ์ด/ลำดับเมือง เป็นของเราเอง — ใช้แค่ "แนวเกม" ไม่ลอกหน้าตาเกมใด

## กติกา
**ตา:** ทอย 2 ลูก · แถบพลัง (กดค้างเล็งช่วงเลข 2–12 · คุมติด 40% → ได้ ±3 จากที่เล็ง ไม่ติด = สุ่ม) · คู่ = ทอยต่อ · คู่ 3 ครั้งติด = เข้าคุก · ตาละ 20 วิ หมดเวลา/หลุด = บอทเล่นแทน
**เงินเดือน:** ผ่านจุดเริ่มต้น
**สร้าง:** ตกที่ว่าง = ซื้อที่ดิน + สิ่งปลูกสร้างในทีเดียว — ยังไม่เคยผ่านจุดเริ่มต้น สูงสุด 2 หลัง · ผ่านแล้ว สูงสุด 3 หลัง · ตกเมืองตัวเองสร้างเพิ่มถึงเพดาน · ครบ 3 หลังแล้วตกซ้ำ = แลนด์มาร์ค · ตกจุดเริ่มต้น = สร้าง/อัปที่เมืองตัวเองได้ 1 เมือง · ท่องเที่ยว = ซื้อที่ได้อย่างเดียว
**ค่าผ่านทาง:** ตามระดับสิ่งปลูกสร้าง × ตัวคูณเทศกาล
**ซื้อต่อ:** จ่ายค่าผ่านทางก่อน แล้วเลือกซื้อ ราคา ×2 ของ (ที่ดิน+สิ่งปลูกสร้าง) — แลนด์มาร์ค/ท่องเที่ยวซื้อต่อไม่ได้ · ซื้อต่อแล้วสร้างเพิ่มได้ทันทีถึงเพดาน
**จ่ายไม่ไหว:** ขายสิ่งปลูกสร้าง/ที่ดินคืนครึ่งราคา (ผู้เล่นเลือก · บอท/หมดเวลา = ขายถูกสุดก่อน) · ขายหมดยังไม่พอ = ล้มละลาย ทรัพย์สินคืนกระดาน
**ช่องพิเศษ:** คุก 2 ตา (คู่ = ออก · จ่ายค่าประกันออกได้) · เทศกาล: เลือกเมืองตัวเอง ค่าผ่านทาง ×2 (มีได้ทีละ 1 เมืองทั้งกระดาน) · เที่ยวรอบโลก: จ่ายค่าบิน ตาหน้าเลือกช่องไปเอง · ภาษี 10% ของทรัพย์สิน · มินิเกม: เกมสั้นในห้อง ได้เงินในเกม (v1 = กดหยุดเข็มนำโชค) · การ์ดดวง
**การ์ดดวง (ถือได้ ≤2 ใบ):** นางฟ้าคุ้มครอง (ไม่จ่ายค่าผ่านทาง 1 ครั้ง) · คูปองครึ่งราคา · กุญแจห้องขัง · ตั๋วเที่ยวรอบโลก · แม่เหล็ก (ดึงคนข้างหน้า ≤6 ช่องมาเมืองเรา) · แปลนก่อสร้าง (สร้าง +1 เมืองตัวเองที่ไหนก็ได้) · ไฟดับ (เมืองคู่แข่ง ค่าผ่านทาง 0 นาน 3 ตา) · พายุ (รื้อชั้นบนสุด 1 ชั้น) — 2 ใบหลังใช้กับแลนด์มาร์คไม่ได้ · จัดเทศกาล · กลับบ้าน · แบ่งปัน (ทุกคนบริจาคให้คนจนสุด) · เข้าคุก · ภาษีฉุกเฉิน
**จบเกม:** ครบ 20 รอบ → ทรัพย์สินรวมมากสุดชนะ · ล้มละลายเหลือคนเดียว · ชนะพิเศษทันที: ครองแถว (ทุกเมือง/ท่องเที่ยวในด้านเดียว) · ครองสามสี (ครบ 3 กลุ่มสี) · ครองท่องเที่ยวครบ 5

## สถาปัตยกรรม
```
src/data/tycoon/board.js        กระดาน ราคา กลุ่มสี (ข้อมูลล้วน)
src/data/tycoon/cards.js        การ์ดดวง
src/utils/tycoon/engine.js      เกมเป็น pure reducer: (state, action, rng) → { state, events }
src/utils/tycoon/rules.js       ฟังก์ชันย่อย ค่าผ่านทาง ซื้อต่อ เพดานสร้าง ชนะพิเศษ
src/utils/tycoon/bot.js         เลือก action จาก state (pure)
src/utils/tycoon/*.test.js      เทสต์ทุกกติกาข้างบน
src/composables/useTycoonRoom.js   ห้องออนไลน์ (RTDB) + ห้องในเครื่อง (บอทล้วน) ใช้ engine ตัวเดียวกัน
src/views/TycoonView.vue + components/tycoon/*   กระดาน ลูกเต๋า แถบพลัง แผงเมือง การ์ด
```
**ออนไลน์:** RTDB `tycoon/rooms/{roomId}` เก็บ state + log action · คนที่ถึงตาเป็นคนรัน engine แล้วเขียน state ใหม่ (transaction กันชน) · host รันบอทและตัดสินคนหมดเวลา/หลุด (host หลุด → คนถัดไปรับช่วง) · rng ใส่ seed ใน state ให้ทุกเครื่องเล่นซ้ำได้
⚠️ ไม่มีเซิร์ฟเวอร์ = คนที่ถึงตาโกงลูกเต๋าได้ — รับได้ในเดโมที่ไม่มีเหรียญ · ก่อนผูกเหรียญต้องคิดใหม่
**สิทธิ์เข้า:** แอดมิน + `config/app.tycoonTesters` (รายชื่อ uid) · RTDB rules ตรวจ `auth != null` + อยู่ในรายชื่อ (อ่านจาก RTDB `tycoon/testers` ที่แอดมินซิงก์)
**ไม่แตะ** user doc / เหรียญ / Firestore rules เดิม

## ลำดับทำ
1. engine + rules + เทสต์ (เล่นจบเกมได้ใน node ด้วยบอทล้วน)
2. หน้าจอกระดาน + เล่นกับบอทในเครื่อง (แอดมินเห็นคนเดียว) → user ลองกด
3. ห้องออนไลน์ 2–4 คน + ล็อบบี้ + เติมบอท + ผู้ทดสอบ
4. จูนตัวเลขกับเพื่อน
