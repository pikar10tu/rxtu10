# ดวงประจำวัน (โซนผ่อนคลาย) — design

วันที่: 9 พ.ย. 2026 · สถานะ: รอ user อ่าน spec

## เป้าหมาย
โซนดูดวงให้เพื่อนในรุ่นที่ชอบดูดวงเข้ามาดูทุกวัน ใช้ระบบ "จริงหรือใกล้เคียงจริง" (ไม่ปรุงมุกสายเภสัช) ไม่มีรางวัล/เหรียญ

## ขอบเขตรอบนี้
1. ไพ่ทาโร่ประจำวัน — Rider–Waite 1909 ครบ 78 ใบ
2. ดวงรายวันตามราศีแบบไทย (นิรายนะ) — จากดวงจันทร์จรจริง
3. สีมงคลตามวันเกิด (ทักษา)
4. ลัคนา — เมื่อมีปีเกิด (เวลาไม่รู้ใช้ค่ากลาง)

ไม่ทำรอบนี้: ดวงคู่ ทำนายฝัน เมนูมงคล ดวงลงทุน ปาจื่อ ดวงรายเดือน

## วางตรงไหน
- **Home**: การ์ด `HoroCard` ต่อจาก `DailyCard`
  - ยังไม่กรอก: "กรอกวันเกิดเพื่อดูดวง" + เปิดไพ่ได้เลย
  - กรอกแล้ว: ราศี + ดวงวันนี้ 1 บรรทัด + สีมงคลวันนี้ → แตะเปิด BottomSheet ดวงเต็ม
- **Me**: ปุ่ม "🔮 ดวงของฉัน" ข้าง `MbtiPicker` ด้านบน → BottomSheet กรอก/แก้ข้อมูลเกิด (ไม่บังสถิติ)

## หน้าต่างดวงเต็ม (BottomSheet)
1. 🃏 ไพ่ประจำวัน — แตะเปิด (พลิก) · seed = hash(uid + วันที่ไทย) → ใบเดิมทั้งวัน · กลับหัว ~30%
2. ♈ ดวงวันนี้ — งาน/การเรียน · การเงิน · ความรัก (1–5 ดาว + ข้อความ) · เลขนำโชค
3. 🎨 สีมงคล — เสริมงาน/การเงิน/เสน่ห์ · สีกาลกิณี
4. ⬆️ ลัคนา (ถ้ามีปีเกิด) — ป้าย "โดยประมาณ" เมื่อไม่ได้ระบุเวลา
- บรรทัดท้าย: "เพื่อความบันเทิง"

## ข้อมูล
- `users/{uid}/private/horo` = `{ d, m, y|null, time:'HH:MM'|null, updatedAt }` — rules: เจ้าของอ่าน/เขียนคนเดียว (แอดมินไม่จำเป็น)
- `users/{uid}.horo` = `{ sign: 0–11, dow: 0–6 }` — ไม่ลับ ใช้แสดงการ์ด Home โดยไม่ต้องอ่านเพิ่ม
- ค่ากลาง: ไม่รู้เวลา → 06:00 (ลัคนา≈ราศีอาทิตย์ แสดงป้ายโดยประมาณ) · ไม่รู้ปี → ไม่คำนวณลัคนา · สถานที่ = กรุงเทพฯ ทุกคน
- ไม่เพิ่ม read ตอนเข้าหน้า Home · อ่าน private doc 1 ครั้งตอนเปิดหน้าต่างแก้ข้อมูล/ลัคนา

## คำนวณ (ในเครื่อง ไม่มี API)
- ราศีไทย: ลองจิจูดดวงอาทิตย์ ณ วันเกิด (เที่ยง หรือเวลาที่กรอก) − Lahiri ayanamsa → ราศี 0–11
- ดวงรายวัน: ลองจิจูดนิรายนะของดวงจันทร์ 12:00 วันนี้ (เวลาไทย) → เรือนที่ (1–12) นับจากราศีเกิด → ตารางคำทำนาย
- ลัคนา: ascendant จากเวลา/วันเกิด + พิกัดกรุงเทพฯ − ayanamsa
- ไลบรารี: `astronomy-engine` (MIT) — โหลดแบบ lazy เฉพาะตอนเปิดดวง
- สีมงคล: ตารางทักษาคงที่ตามวันเกิด (ตาราง 7 วัน) · วันพุธกลางคืนนับเป็นราหู เมื่อกรอกเวลา ≥ 18:00
- เลขนำโชค: จาก seed uid+วันที่

## เนื้อหา (โทน B: หมอดูใจดี)
- โครง: ความหมาย 1–2 ประโยค + "✦ คำแนะนำ:" 1 บรรทัด · กลับหัว = บอกสิ่งที่ต้องระวังพร้อมทางออก ไม่ขู่
- ไพ่: 78 × (หัวตั้ง/กลับหัว) = 156 ชุด ยึดความหมายตามตำรา RWS
- ดวงรายวัน: 12 เรือน × 3 ด้าน × 2–3 แบบ (สุ่มด้วย seed วัน) + ดาว 1–5 ต่อด้านตามเรือน
- ขั้นตอน: เขียนชุดตัวอย่าง (ไพ่ 10 ใบ + 3 เรือน) ให้ user ตรวจโทนก่อนเขียนครบ

## ภาพ
- RWS 1909 จาก Wikimedia Commons (สาธารณสมบัติ) — ห้ามใช้ฉบับลงสีใหม่ U.S. Games 1971
- WebP กว้าง ~260px ใบละ ~30KB → `public/tarot/` · ด้านหลังไพ่ลายของเว็บเราเอง · โหลดเฉพาะใบที่เปิด

## เทส
- `utils/horo.js` (ตรรกะล้วน) + `horo.test.js`: ราศีไทยวันขอบ (13–15 เม.ย.), เรือนจันทร์, seed คงที่ทั้งวัน, ค่ากลางเวลา, สีวันพุธกลางคืน
- เทียบราศี/ลัคนากับโปรแกรมโหราศาสตร์ไทยสัก 3 วันเกิด
- ดูจอจริงผ่าน Chrome ก่อน push · deploy rules ก่อน push
