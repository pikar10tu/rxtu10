## 4. กลไกที่ต้องเขียนใหม่

### 4.1 👹 ง้างตะบองฟาด! (`effect: 'windup'`, value `{ pct: 300 }`)
- ตาแรกของโอนิในไฟต์: **ไม่ตี** ขึ้นแบนเนอร์/ป้าย "ง้างตะบอง…" (นับว่าได้ตาในรอบแล้ว เหมือนตาที่ถูกข้าม)
- ตาถัดไป: ฟาด ×pct% · ถ้าหมัดนั้นน็อกเป้า ⇒ ตีต่อทันที 1 ครั้ง ×pct% เท่าเดิม (ตีต่อไม่ใช่ตาใหม่)
- แล้ววน ง้าง → ฟาด ไปเรื่อยๆ
- ถูกแช่แข็ง (skip) ตอนตาฟาด = ตานั้นหาย สถานะ "ง้างแล้ว" ค้างไว้ (ฟาดตาถัดไป)
- ลบ `killChain` ออกจากเอนจิน/beats ถ้าไม่มีเพ็ทใช้แล้ว (ตรวจเทสที่อ้างถึง) · ตีต่อใช้ทาง beat เดียวกับ killChain เดิม
- ป้ายบนการ์ด (`ownCounter`): แสดงสถานะ "ง้าง" ระหว่างรอฟาด
- ข้อความ: desc `ตาแรกง้างตะบอง ตาถัดไปฟาด {pct}% · ฟาดน็อกได้ตีต่ออีก 1 ครั้ง แล้ววนง้างใหม่` · short `ง้าง 1 ตา → ฟาด {pct}% · น็อกแล้วฟาดต่อ`

### 4.2 ☀️ ซอลขั้นบันได
- value `{ common: 50, rare: 40, epic: 30, legendary: 0 }` · นับตาม `countsAs || rarity` เหมือนเดิม · ซอลเองไม่ได้
- ข้อความเอิร์ธที่อ้างซอล (ร่างองศา "นับเป็น common") ต้องยังถูก — ร่างองศาได้ +50%
- desc `เพื่อนในทีมได้พลังโจมตีและเลือด +% ตามระดับ: ธรรมดา {common}% · หายาก {rare}% · เอพิค {epic}%`

### 4.3 🦖 ทีเร็กซ์
- ทุกหมัดที่ตัวเองตี (หมัดหลัก ไม่นับ sub) ⇒ +pct% ของ **atk ตั้งต้น** (บวก ไม่ทบต้น) · ไม่มีเพดาน · เริ่มไฟต์ `start: 2` ชั้น
- hook ย้ายจาก `onAnyDeath` → `onAttack` (หรือหลังหมัด) · กฎ "stackAtk ห้ามเกิน 1 part" ยังคง
- ⚠️ stackAtk เดิม `u.atk *= 1+pct` = ทบต้น — ต้องเปลี่ยนเป็นบวกจากฐานสำหรับตัวนี้ ไม่ไปกระทบ stackAtk อื่น (ถ้ามี)
- desc `ทุกหมัดที่ตี พลังโจมตี +{pct}% สะสมไม่มีเพดาน · เข้าไฟต์พร้อม {start} ชั้น`

### 4.4 🦅 กริฟฟิน · 🦠 ไวรัส · 🐹 แฮมสเตอร์
- กริฟฟิน: `atkMult *= 2 − hp/maxHp` ของเป้า (หลังเลือกเป้า) · ป้ายโชว์ +% จริง
- ไวรัส: loop แปะชั้นให้ `alive(team ศัตรู)` ทุกตัว · event เดียวหลายเป้า (ไม่ใช่ 3 event) กัน beat รก · เจ้าของสแตค = ไวรัสตัวแรก (กฎเดิม)
- แฮมสเตอร์ช่อง 1: ตัดสินในบรรทัด `first` ของ `simulateBattle` · ข้อความเพิ่ม "· อยู่ช่อง 1 ทีมได้ตีก่อน"

## 5. ป้ายคอมโบสดในหน้าจัดทีม (`TeamPicker.vue`)

ใต้ทีม 3 ช่อง แสดงชิปเฉพาะพาสสีฟที่มีเงื่อนไขขึ้นกับทีม — บอกว่าทำงาน/ไม่ทำงาน ไม่บอกว่าทีมไหนดี:
- 🦁 สิงโต: ✅ ครบ 3 สาย ทั้งทีม +12% / ⚠️ ยังขาดสาย X
- ☀️ ซอล: ✅ บัฟ N ตัว / ⚠️ เพื่อนเป็นตำนานหมด ไม่ได้บัฟ
- 🌍 เอิร์ธ: ช่อง N = ☀️/🌧️/❄️ + ผลสั้นๆ
- 🐹 แฮมสเตอร์: ✅ ช่อง 1 ทีมตีก่อน / 💡 ย้ายไปช่อง 1 ทีมจะได้ตีก่อน
- ดูโอ้ (`DUO_TITLES` / คู่): ✅ ชื่อคู่ เมื่อครบ
- logic เป็น pure function `utils/teamSynergy.js` (มีเทส) · เลขมาจาก `passiveValueAt` ตามขั้นจริง ห้ามพิมพ์เลขตรง
- ข้อความตาม voice-guide · ฟอนต์ ≥ .7rem
