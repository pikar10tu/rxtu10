## 1. ทะเบียนสนาม `src/data/arenas.js`

```js
{ id:'ar-lab', name:'ห้องแล็บเภสัช', tier:'rare', src:'shop', floor:'lab',
  deco:[['🧪',12,.5,1.7,.7], ...],      // [อีโมจิ, x%, d, ขนาด rem, ความทึบ, อนิเมชัน?]
  petals?:'🌸',                        // ของขยับ ≤ 2 ชิ้น
  sale?:{ from:'2026-10-01', to:'2026-12-10' },   // ลิมิเต็ดเท่านั้น (เวลาไทย)
  season?:'2026-09',                   // แชมป์เท่านั้น
  power?:null }                        // เผื่ออนาคต ห้ามใช้ตอนนี้
```

- ราคามาจาก `ARENA_TIERS = { rare:10000, epic:50000, legendary:100000 }` ไม่เขียนราคาในแต่ละชิ้น
- 🔑 **id ห้ามเปลี่ยน/ห้ามลบ** (กฎเดียวกับ `data/cosmetics.js`) — ขี่แถว roster และอยู่ใน user doc
- หน้าตาพื้นอยู่ใน `src/styles/arenas.css` (คลาส `arf-<floor>`) ใช้ `var(--far)` เป็นทิศขอบจอ
- **สนามต้องออกแบบเป็นมุมมองจากด้านบน** — สนามเดียวกันต้องอยู่ได้ทั้งครึ่งบนและครึ่งล่าง
- ชุดแรก (ตามเดโม): ฟรี `ar-sand` · RARE `ar-grass` `ar-lab` · EPIC `ar-sakura` `ar-beach` `ar-apoth` · LEGENDARY `ar-volcano` `ar-space` `ar-gold` · ลิมิเต็ด `ar-exam` (RARE ขาย 1 ต.ค.–10 ธ.ค.) `ar-loy` (EPIC ขาย พ.ย.) · แชมป์ `ch-2026-09` King of the Jungle

## 2. ข้อมูลผู้เล่น

**user doc** `arenas: { owned: [id...], on: id|null, champ: { '2026-09': 3 } }`
- `champ` เก็บอันดับที่ได้ของแต่ละซีซั่น (1–10) ใช้ตัดสินหน้าตาป้าย
- `arenaOf(u)` (pure ใน `utils/arenas.js`) กรองของที่ไม่อยู่ในทะเบียน · `on` ไม่อยู่ใน owned = ใช้ `ar-sand`
- ซื้อ: pattern เดียวกับ `canBuy/afterBuy` ของ cosmetics — ตัดเหรียญ + เพิ่ม owned + ใส่ทันที ในการเขียนครั้งเดียว

**แถว roster** `ar: 'ar-lab'` หรือ `'ch-2026-09#3'` (แชมป์พ่วงอันดับ) · ใส่ `ar-sand` = ไม่ใส่คีย์
- ราว 15B × 105 คน ≈ 1.6KB

## 3. รีเพลย์ (BattleReplay.vue)

### 3.1 พื้นครึ่งสนาม
- `.br-ov` มี 2 ชั้นพื้น (`.br-bg.top` / `.br-bg.bot`) อยู่ใต้ `.br-box` · เส้นกลาง = กึ่งกลางแถว `.br-vs` วัดด้วย `getBoundingClientRect` ตอน mount + `resize`
- ธีมเดิม `br-theme-tower` / `br-theme-arena` ย้ายไปเป็นพื้นชื่อ `tower` กับ `sand`
- props ใหม่ใน `data`: `arenas: { top: 'ch-2026-09#3', bot: 'ar-lab' }` · ไม่ส่ง = `sand` ทั้งสองฝั่ง (ทุกที่เดิมยังทำงาน)
  - บุกในสนามประลอง: บน = `ar` ในแถว roster ของคู่ต่อสู้ (บอท = sand) · ล่าง = ของเรา
  - ถ้ามีรีเพลย์จากประวัติ: บน = อีกฝ่าย · ล่าง = ของเรา เสมอ
  - ท้าสู้จากโปรไฟล์: บน = คนที่เราท้า
  - หอคอย: บน = `tower` · ล่าง = ของเรา

### 3.2 วางของตกแต่ง (pure `utils/arenaLayout.js` + เทส)
อินพุต: ขนาดเขต, ขนาดของแต่ละชิ้น, รายการ deco · เอาต์พุต: ตำแหน่ง หรือไม่วาด
1. **เขตขอบนอก** = ระหว่างขอบจอกับ `.br-box` ของฝั่งนั้น — ของตกแต่งห้ามแตะกล่องต่อสู้เด็ดขาด
2. ป้ายสลักแชมป์วางก่อนเสมอ
3. ชิ้นถัดไปถ้าชนของที่วางแล้ว → ลองชิดขอบจอฝั่งเดิม → ลอง d = 1 แล้ว d = 0 → ถ้ายังไม่มีที่ก็ไม่วาด
4. ไม่วัดขนาดใน render loop — วางครั้งเดียวตอนเปิดรีเพลย์และตอน resize

เดโมตรวจแล้ว 4 ขนาดจอ × 13 สนาม × 4 อันดับ ไม่ทับกล่องต่อสู้ (iPhone SE ตัดแค่ 🌴 ชิ้นเดียวของสนาม Jungle)

### 3.3 ป้ายชื่อ + ฉาก VS
- `.br-side` ("ศัตรู / ทีมคุณ") เปลี่ยนเป็นป้ายชื่อ `● ชื่อ · แต้ม · ชื่อสนาม` (หอคอยใช้ "ชั้น N")
- สนามประลองกับท้าสู้: ฉาก VS ~1.1 วิ แทน READY/GO (ครึ่งบนสไลด์ลง ครึ่งล่างสไลด์ขึ้น ชนที่เส้นกลาง) · แตะข้ามได้เหมือนเดิม · หอคอยคง READY/GO
- สนามที่ `heavy` (LEGENDARY/แชมป์) ใช้แค่ CSS รอบนี้จึงไม่ต้องโหลด — ถ้าวันหน้าเป็นรูปภาพ ค่อยเพิ่ม "กำลังจัดสนาม…"

### 3.4 เลขดาเมจแบบ B
- แก้ `battleFx.js` `pop()` เดิม (พูล 16 ชิ้น ห้ามสร้าง DOM ระหว่างไฟต์): ทุก `.brfx-pop` มีลูก `.burst` สร้างครั้งเดียวใน `buildPools`
- สีดาว: ปกติส้ม · crit แดงใหญ่ขึ้น + ป้าย CRITICAL · heal วงกลมเขียว · weak/ชนะทาง เทา · super ส้มเข้ม · infect ม่วง
- ขนาดดาวเล็กกว่าเดโมรอบแรก (2.7em / crit 2.9em) กันล้นทับการ์ดข้างๆ
- ฟอนต์ Lilita One โหลดแบบ subset เฉพาะ `+-0123456789` (`&text=`) เพิ่มท้ายลิงก์ Google Fonts ใน `index.html`
- keyframe ขยับแค่ transform/opacity · คงบันได `stackAt` เดิม (เลขซ้อนขึ้นเป็นชั้น ไม่สุ่ม)

### 3.5 แบนเนอร์คัทอิน
- แทน `.br-spot-card` ด้วยแถบเฉียงพาดกล่อง: หน้าเพ็ทเจ้าของ 78px + ชื่อสกิล + คำอธิบาย + "ชื่อทีม · หน้าเพ็ท"
- ทีมเรา: สีฟ้า เข้าจากซ้าย · ศัตรู: สีแดง เข้าจากขวา
- **หน้าเจ้าของสกิลทุกครั้ง** (เดิมมีแค่ยกแรกผ่าน `opts.icon`): หาเพ็ทจาก `e.uid` แล้วใช้ `defOf(id).emoji` (แบบเดียวกับการ์ดในทีม)
- จังหวะคงเดิม: `spotlightPassive` await อยู่แล้ว ⇒ ไม่มีใครตีระหว่างแบนเนอร์ · ผลลงตอนแบนเนอร์เลื่อนออก
- การ์ดเพ็ทเจ้าของยก z-index เหนือม่านมืด (`.spotlit` เดิม)

### 3.6 กติกา perf (ห้ามละเมิด — ดู memory battle perf / CLAUDE.md)
- ขยับได้แค่ transform/opacity · ห้าม blur/filter/เงาที่ขยับ/เขย่าทั้งจอ
- ของขยับบนพื้นสนาม ≤ 2 ชิ้นต่อฝั่ง · แสงวิ่งป้ายที่ 1 นับเป็น 1 ชิ้น
- เช็คโหมดลดการเคลื่อนไหวผ่าน `prefersReducedMotion()` เท่านั้น (CLAUDE.md ข้อ 11 — ตอนนี้คืน false ทั้งเว็บ) ห้ามเขียน `@media (prefers-reduced-motion)` เพิ่ม
- ตัวอักษรทุกจุด ≥ .7rem (CLAUDE.md) — เดโมมีป้าย CRITICAL / เดือนใต้ป้ายสลัก / ป้ายระดับ ที่ต่ำกว่านี้ ต้องขยายตอนทำจริง
- overlay ใหม่ (ชีตเปลี่ยนสนาม) ต้อง Teleport to body + z-index ตามบันได CLAUDE.md ข้อ 6 / 12
- ⚠️ ต้องวัดบน iPhone จริงด้วย `?fps=1` ก่อน merge (Chrome บนคอมวัดไม่ได้)

## 5. สนามแชมป์ + รางวัลซีซั่น
- `SEASON_REWARDS.arena.topN` 3 → 10 · achievement `arena_champ` ยังให้เฉพาะท็อป 3 เหมือนเดิม
- อันดับ = 1 + จำนวนคนที่แต้มมากกว่า (เท่ากันได้อันดับเดียวกัน) · กติกาเส้นตัดเดิม: เท่ากันที่อันดับ 10 ได้ทุกคน
- จดหมายรางวัลอารีน่าแนบ `reward.arena = { id:'ch-2026-09', rank }` · `canClaim` นับว่ามีรางวัล · ตอนกดรับ: เพิ่ม owned + `champ[season] = rank` (ถ้าเคยได้อันดับดีกว่า เก็บอันดับที่ดีกว่า)
- ป้าย: `TOP n · ARENA CHAMPION` (1–3) / `TOP 10 · ARENA ELITE` (4–10) + `SEPTEMBER 2026` จาก `season`
- **ทุกเดือนต้องเพิ่มสนามแชมป์เดือนนั้นในทะเบียนก่อนกดแจก** — ปุ่มแจกเตือนถ้ายังไม่มี `ch-<season>` (ไม่แนบสนาม แต่ยังแจกเหรียญ/achievement ได้)
- ⏰ เป้าหมาย: deploy ก่อนเที่ยงคืน 1 ต.ค. ถ้าไม่ทัน: ผล ก.ย. อยู่ใน `pvp.last` ถึงรีเซ็ต 1 พ.ย. ⇒ ทำปุ่ม "แจกสนามแชมป์ย้อนหลัง" คำนวณจาก `pvp.last` ได้ตลอดเดือน ต.ค.
