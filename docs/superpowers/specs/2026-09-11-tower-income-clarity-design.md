## การคำนวณส่วนต่าง

แหล่งเดียว: ฟังก์ชันใหม่ใน `data/towerFloors.js`

```js
/** ส่วนต่างโบนัส/วัน ที่จะได้เพิ่มถ้าชนะชั้น `floor` (0 = ไม่เพิ่มแล้ว เช่นเลยเพดาน) */
export function towerBonusGain(floor, best) {
  const after = getTowerBonus(Math.max(best || 0, Math.floor(floor) || 0))
  return Math.max(0, after - getTowerBonus(best || 0))
}
```

- `max(0, …)` กันค่าติดลบตอนแอดมินกด "รีเซตชั้นหอคอย" (ชั้นปัจจุบันต่ำกว่า best ได้)
- ชั้น 71+ คืน 0 เสมอ (เพดานที่ `BONUS_CAP_FLOOR = 70`)

## พฤติกรรมตอนเต็มเพดาน (ชั้น 71+ / gain = 0)

**ห้ามโชว์ `+0/วัน`** — ดูเหมือนบั๊ก

- จุด 1 บรรทัดสอง → `เพดานรายได้เต็มแล้ว · ไต่ต่อเพื่ออันดับ` (แทนบรรทัด `ชนะชั้น … →`)
- จุด 2 ปุ่มสู้ → กลับเป็น `⚔️ สู้ชั้น 71` เฉยๆ ไม่มีท้าย
- จุด 3 จอชนะ → `🎁 ขึ้นชั้น 72 · รายได้ 20,000/วัน (เต็มเพดาน)`

## เคสขอบอื่น

- **ผู้เล่นใหม่ (`best = 0`, `floor = 1`)** — จุด 1 บรรทัดแรกขึ้น `หอคอยให้รายได้ 0/วัน` ซึ่งเป็นข้อความที่ถูกต้องและเป็นการชี้ทางในตัว (บรรทัดสองจะบอก `ชนะชั้น 1 → 50/วัน (+50)`)
- **จุด 6 ตอน `towerBonus = 0`** ใช้ชั้น 10 (`+675/วัน`) เป็นตัวอย่างเป้าหมาย เพราะเป็นระยะที่ไปถึงได้ในวันเดียวและตัวเลขใหญ่พอให้สนใจ — hardcode ค่าชั้นไว้ที่เดียวเป็นค่าคงที่ ไม่ใช่เลขลอย
