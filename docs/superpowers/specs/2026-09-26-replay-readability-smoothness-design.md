## ปัญหา

1. **อ่านไม่ทัน แต่ไม่อยากให้ยาว** — user: ตามไม่ค่อยทันว่าเลือดลด + ชื่อสกิล/คัทอิน "แต่ก็ทันอยู่ บอกไม่ถูก"
   สาเหตุจากโค้ด (`components/battle/BattleReplay.vue`):
   - หลอดเลือดสูง 7px
   - หลอดผี (ดาเมจที่เพิ่งกิน) สีขาว opacity .75 · delay .16s หด .45s ⇒ หายก่อนหมัดถัดไป
   - เลข HP (`curHp`) กระโดดค่าทันที ไม่ไล่
   - เลขดาเมจกลางการ์ด / หลอดใต้การ์ด = ตาต้องกระโดดสองจุด
   - ชิป/แบนเนอร์สกิลขึ้นแล้วหายถาวร
   - ทุกหมัดปกติยาวเท่ากัน (`BEAT=520`) ไม่ว่าจะลดเลือดมากหรือน้อย
2. **กระตุก** — iPhone 13 <30fps ~140 เฟรม/ไฟต์ ถอยจาก ก.ค. ("ลื่นมาก") · ยังไม่รู้ตัวการ (v3 bisect ยังไม่ได้เทส)

**เงื่อนไข:** ความยาวไฟต์รวมต้องเท่าเดิม (~23.3s ±5%) · เครื่องเทสคือมือถือ user คนเดียว (ตัวแทนเครื่องกลางๆ)

## ส่วนที่ 1 — ห้องเทียบ v4 (artifact)

ต่อยอด `D:/RXTU/_replay-lab/` (bundle โค้ดจริง) · publish ทับ URL เดิม `https://claude.ai/artifact/AgpVu7S3FrrYT2TM6dw7dZ` (แชร์ได้ "Anyone with the link")

แผง 3 แผง · ทุกแผงมีปุ่มพรีเซ็ต **"ตอนนี้" / "แนะนำ"** · ปุ่มเล่นไฟต์เดิมซ้ำ (log เดิม seed เดิม)

**แผงอ่านง่าย (A)**
- ความสูงหลอด 7 / 9 / 11px
- หลอดผี: ขาวจาง ↔ เหลือง/ส้ม · ค้าง .45s ↔ .8s
- เลข HP: กระโดด ↔ ไล่นับลง + กระพริบแดง
- ไอคอนสกิลค้างบนการ์ดหลังโปรกครั้งแรก เปิด/ปิด

**แผงจังหวะ (B)** — สไลเดอร์ "ความต่างของหมัด" (`HIT_SPREAD` 0 → สูง)
- 0 = ของเดิม ทุก `hit` = `BEAT`
- >0: เวลาของ `hit` แปรตาม `weight` (หนัก = ยาว เบา = สั้น) แล้วสเกลให้รวมเท่าของเดิม
- `ko`/`finish`/สกิล ไม่แตะ
- โชว์ความยาวไฟต์รวม vs ของเดิมตลอด

**แผงกราฟิก (หาตัวการ)** — สวิตช์ปิดทีละตัว: พื้นสนาม · อนิเมชันพื้น (ambient infinite) · เลข B (stroke + clip ดาว) · คัทอิน · squash/จอสั่น · เสียง
- ตารางผลหลังจบไฟต์: จำนวนเฟรม <30fps · เฟรมแย่สุด · ชุดสวิตช์ที่ใช้ (สะสมหลายรอบให้เทียบ)

## ส่วนที่ 2 — ลงของจริง (หลัง user เลือกค่า)

**2.1 ค่าที่เลือก**
- `utils/battleBeats.js`: เพิ่ม `HIT_SPREAD` ในบล็อกค่าจูนเดิม · `kind` คุมเวลา / `weight` คุมความดัง ยังแยกกัน — ที่นี่ `weight` ถูกอ่านเพื่อ*กระจาย*เวลาภายใน kind `hit` เท่านั้น ไม่เปลี่ยน kind
- เทส: ความยาวไฟต์รวมจาก log จริง 200 ไฟต์ ต้องอยู่ใน ±5% ของ `HIT_SPREAD=0` · SHAPE ยังรวมได้ 1
- `BattleReplay.vue`: หลอด/หลอดผี/เลข HP/ไอคอนสกิล — transform/opacity เท่านั้น ไม่เพิ่ม layer ขณะการ์ดวิ่ง (กฎ v3 [battle perf]) · ไอคอนสกิลใช้แพทเทิร์น span static แบบ `.br-skill-dot`/ป้ายสถานะ (cap เดิม)
- เลข HP ไล่นับ: ไม่ใช้ reactive ทุกเฟรมบนการ์ด promote — ถ้าวัดแล้วแพง ให้ตกกลับเป็นกระพริบอย่างเดียว

**2.2 แก้ตัวการที่ห้องเทียบเจอ** — วิธีแก้ขึ้นกับผล จะเสนอ user อีกรอบก่อนลงมือ

**2.3 ลดคุณภาพอัตโนมัติ**
- วัดเฟรมช่วงฉาก VS/ยกแรก (ใช้ frame meter ที่มีอยู่ ตัวจูนคาบจอ) · ถ้า >25% ของเฟรม <30fps → ลด 1 ขั้น
- ลำดับปิดตามราคาที่ห้องเทียบวัดได้ (แพงก่อน)
- ห้ามปิด: เลขดาเมจ · หลอด · ชื่อสกิล
- จำขั้นใน localStorage (try/catch) ต่อเครื่อง · ไฟต์ถัดไปเริ่มที่ขั้นนั้น

**2.4 นาฬิกาเดียว (setTimeout + WAAPI → clock เดียว)** — ⏸️ ไม่อยู่ในรอบนี้ ดูผลหลัง 2.1–2.3 ก่อน ทำเฉพาะถ้ายังเห็นเลขหลุดจังหวะชน
