- เพื่อนกดรับรางวัลซีซั่นในหน้าโหมดที่เล่นจริง (หอคอย / อารีน่า) พร้อมอนิเมชันเปิดรางวัล แทนการรับในกล่องจดหมาย
- รางวัลช่องว่างแคบลง: หอคอยแจกตามชั้น (ไม่ดูอันดับ) · อารีน่าทุกคนได้ตั๋ว คงขั้นอันดับ 1/2/3

## ที่เก็บ: จดหมายเดิม ติดป้าย
- `seasonRewardMails` เพิ่มฟิลด์ `kind: 'season'`, `mode: 'tower'|'arena'`, `season`, และ `tier` (ข้อมูลโชว์: `best` หรือ `rank`/`rating`, ชื่อขั้น)
- `buildBroadcastMail` ส่งฟิลด์เหล่านี้ผ่าน (optional) · rules ไม่ต้องแก้ (academic create ได้ทุกแบบ · owner update แค่ read/claimed)
- กดรับ = `mailbox.claim(id)` ตัวเดิม
- ไม่อ่าน Firestore เพิ่ม: หน้าโหมดเรียก `mailbox.load()` (cache ต่อ uid อยู่แล้ว)

## หน้าจอ
- `SeasonClaimBanner.vue` (props `mode`) วางบนสุดของหน้าหอคอยและหน้าอารีน่า
  - หา mail `kind==='season' && mode===props.mode && !claimed` ล่าสุด → โชว์แบนเนอร์ (ชั้น/อันดับ, ชื่อขั้น, ปุ่ม 🎁 รับรางวัล)
  - ไม่มี = ไม่แสดงอะไร (ไม่มีสถานะ "รับแล้ว" ค้างถาวร — โชว์ ✓ แค่ในรอบที่เพิ่งกด)
- `SeasonClaimReveal.vue` overlay **Teleport to body** (CLAUDE.md ข้อ 6)
  - จังหวะตามเดโม: กล่องสั่น (ยาวตาม lv 1–4) → เปิด + เหรียญพุ่ง canvas → แถวรางวัลเด้งทีละแถว ตัวเลขนับขึ้น → ของพิเศษกรอบทองแถวท้าย → ปุ่ม "เก็บเข้ากระเป๋า"
  - แตะที่ไหนก็ได้ = ข้าม · `prefers-reduced-motion` = ไม่มีอนิเมชัน
  - ไอคอน WebP ของเว็บแทนอีโมจิ · เสียงจาก `utils/sfx.js`
  - เรียก `claim` ตอนกดปุ่มรับ (ก่อนเล่นอนิเมชัน) · ล้มเหลว = ปิด overlay + toast ไม่เล่นอนิเมชันโกหก
- lv ของขั้น: หอคอย 1–19/20–39 → 1, 40–59/60–79 → 2, 80–99 → 3, 100 → 4 · อารีน่า 11+ → 1, 4–10 → 2, 2–3 → 3, 1 → 4
